# PRD

Read [the canonical PRD command](../../../.claude/commands/prd/SKILL.md) and use the supplied `new`, `review`, or `list` request and its arguments as `$ARGUMENTS`. Follow the selected mode and consult `docs/prd/README.md` for the project standard.

Use `AGENTS.md` for project conventions and graph-first verification of claims about ByroRedux code. In review mode, leave the owner to decide the PRD status and use `codex` as the reviewer in the proposed log row.
