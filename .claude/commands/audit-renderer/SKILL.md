# Renderer Audit

Read `.claude/commands/_audit-common.md` and `.claude/commands/_audit-severity.md` for shared protocol (layout, Key Reference Docs, methodology, dedup, context rules, finding format; the RT/SSBO/GPU-struct/denoiser severity floors used below).

Audit the Vulkan renderer's GPU *shading and sync correctness*: ray tracing, SSBO/UBO indexing, GPU-struct layout, synchronization, GPU memory, the deferred-lighting/resolve chain (G-buffer, SVGF, composite, TAA, bloom, FSR, presentation) and the per-feature passes.

**Architecture**: Orchestrator. Each dimension runs as a Task agent (max 3 concurrent).

**Do NOT restate** GPU-struct layouts, descriptor bindings, G-buffer formats or submission order here — `docs/engine/shader-pipeline.md` is the code-verified reference; `docs/engine/memory-budget.md` owns VRAM/RAM ceilings, LRU thresholds, deferred-destroy depth. Audit *against* them; a divergence is a finding (or the doc is stale — say which).

**Scope boundary.** Ground cover, sky-cube bake/prefilter/SH, cloud march, weather/sun, terrain splat/LOD and water *translation* belong to `/audit-exterior`. This skill keeps the *renderer-wide* rules those passes obey (struct lockstep, barriers, teardown, descriptor lifecycle, shading-side consumption) — apply Dims 3/4/5 to their resources; do not audit their content.

## Verification discipline (No-Guessing)

- Anchor findings on symbols (`fn`/`struct`/`const`/test names), never `file:NN`; confirm by `grep`; drop unconfirmable claims. Backticked `.ext` paths must resolve now (`_audit-validate.sh`).
- Recast resolved issues as regression guards ("verify X still holds").
- **No speculative Vulkan changes**: never propose render-pass/pipeline/barrier edits whose failure is invisible to `cargo test`; frame as **needs RenderDoc** (or a `BYRO_VALIDATION=1` sync-validation run) and stop at the observation.
- Never hard-code FPS/ms; cite ROADMAP.md Bench-of-record (flagged stale).
- **Guard-first**: for each `Guard:` line, run the named `cargo test -p byroredux-renderer <filter>`, confirm the tests exist, are not `#[ignore]`d and not vacuous, then spend the budget on what the guard cannot see. Source-shape tests prove a string is present, not that the GPU behaves.

## Parameters

- `--focus <dimensions>`: comma-separated numbers (e.g. `1,3,7`). Default all. `--depth shallow|deep`: patterns only vs traced invariants. Default `deep`.

## Extra Per-Finding Fields

- **Dimension**: AS Correctness | Ray Queries | GPU-Struct Layout | Material Table | Sync/Barriers | Pipeline/RenderPass | Memory/Lifecycle | NIFAL Material | Tangent-Space | Denoiser/Composite | TAA | Bloom | Volumetrics | Caustics | Water | Skinning | Camera-Relative Precision | Disney BSDF | Soft Shadows | Sky/Weather | Light Animation | FSR/Presentation | Debug/Telemetry | Cornell Harness

## Phase 2: Dimensions

Ordered by risk: AS/SSBO indexing and struct layout corrupt every frame silently; sync/memory compound; shading is mostly visual.

### CRITICAL tier — silent whole-frame corruption

#### Dimension 1: Acceleration structures (BLAS/TLAS)
**Paths**: `crates/renderer/src/vulkan/acceleration/`, `context/resources.rs` (`build_blas_batched`, `restore_missing_static_blas_for_draws`), `context/skinned_blas_refit.rs`, `context/dispatch_skin_and_cluster.rs` (TLAS build site), `byroredux/src/app_step.rs` (`step_static_blas_restore`).
**First step**: `git log --since=… --format='%h %s' -- crates/renderer/src/vulkan/acceleration crates/renderer/src/vulkan/context/resources.rs`
**Floor**: wrong geometry/address = CRITICAL; freeing an AS an in-flight frame still reads = CRITICAL; missing build→read barrier = HIGH.
**Guard**: `cargo test -p byroredux-renderer acceleration` (`acceleration/tests/`: scratch-serialize barriers, build→ray-query barrier on both `build_tlas` arms, deferred-destroy countdown, residency accounting, admission gates, telemetry reachability) + `build_tlas_is_preceded_by_an_unconditional_as_write_to_as_read_barrier` (`dispatch_skin_and_cluster.rs`) + `static_blas_recovery_covers_both_sources_and_protects_current_draws` (`resources.rs`) + `static_blas_recovery_runs_between_frames_not_in_the_render_driver` (`app_step.rs`).
**Checklist** (what the guards cannot see):
- BLAS geometry `R32G32B32_SFLOAT` @ 0, `UINT32` indices, `OPAQUE`. Flags (`acceleration/constants.rs`): `STATIC_BLAS_FLAGS` (`FAST_TRACE|ALLOW_COMPACTION`), `SKINNED_BLAS_FLAGS` (`FAST_BUILD|ALLOW_UPDATE` — deliberate, measured), `UPDATABLE_AS_FLAGS` (TLAS); `BlasEntry.built_flags` must equal the refit flags (VUID-03667).
- **`instance_custom_index` == instance SSBO index** — the load-bearing AS/SSBO contract (24-bit field; `MAX_INSTANCES < 1 << 24` const-asserted). Padded/unused slots must not break UPDATE mode; the build/update decision keys on `last_blas_addresses` only.
- Transform column-major `mat4` → 3×4 row-major; `TRIANGLE_FACING_CULL_DISABLE` is gated on `draw_cmd.two_sided` — keep the gate (it records the same two-sided intent the raster PipelineKey does). The old "~2× ray cost / RT honors the bit" premise was wrong (#4580): no shader ray requests facing culling, so the bit changes nothing today; every ray already sees both faces. A future facing-cull ray flag must revisit the gate.
- Instance mask (`shadow_mask_for_instance`, `mask_divert_cause`, `predicates.rs`): every actor/glass/effect instance lands in exactly one category; refractive glass (incl. multi-layer-parallax refractors) and effect kinds stay outside the opaque shadow cull mask.
- BLAS budget = `blas_budget_for_heap(heap, reserved)`, the reservation from `screen_scaled_reservation_bytes` (formula and eviction policy: `/audit-performance` Dim 3): verify it bills every render-extent pass, the output-extent upscaler images and FSR SDK bytes, and is re-derived on resize **after** the upscaler is recreated (`context/resize.rs`).
- Shrink wiring: `shrink_tlas_scratch_to_fit` + `shrink_tlas_to_fit` end `draw_frame`; `shrink_blas_scratch_to_fit` runs at cell unload (`cell_loader/unload.rs`) and resize; constants match memory-budget.md.
- `rt.integrity` chain: `integrity_snapshot()` → `fill_rt_integrity_stats` (`context/telemetry.rs`) → `RtIntegrityStats::verdict` (`tlas_emitted == tlas_eligible`, all three `missing_blas` counters zero) runs per frame. Grep the METHOD `integrity_snapshot`, not the struct (struct-grep produced two false "no reader" findings).
- **Documented ceilings — quantify before filing**: (a) a synchronous multi-cell `--grid` burst can false-evict a not-yet-drawn BLAS via the shared `frame_counter` bump ("Deferred pending a" in `blas_static.rs`; unreachable while static BLAS bytes ≤ budget on the 12 GB dev card); (b) all skinned builds/refits share one scratch and serialize.
**Output**: `/tmp/audit/renderer/dim_1.md`

#### Dimension 2: Ray-query shading & coordinate spaces
**Paths**: `crates/renderer/shaders/{triangle.frag,triangle.vert,water.frag}`, `shaders/include/{raytrace,ray_hit,ray_origin,lighting,shadow_common,shadow_transport,mesh_id}.glsl`, `scene_buffer/ray_budget.rs`, `byroredux/src/render/camera.rs`, `crates/core/src/ecs/components/camera.rs`.
**First step**: `git log --since=… --format='%h %s' -- crates/renderer/shaders`, then `cargo test -p byroredux-renderer shader_contract`.
**Floor**: SSBO index mismatch = CRITICAL; self-intersection / wrong tMin = HIGH; a path mixing the two coordinate conventions = HIGH.
**Guard**: `cargo test -p byroredux-renderer shader_contract` (`scene_buffer/shader_contract_tests.rs` — GLSL source-shape: scale-aware ray origins, render-origin-relative varying + skinned rebase, bindless-index masking, shared raster/ray alpha chain, Gram-Schmidt zero guards, stable-surface-ID reservoirs, GI zero-budget floor), `triangle_frag_keeps_glass_identity_and_ior_across_rt_lods` (`shader_constants.rs`), the `depth_convention` tests.
**Checklist**:
- `instance_custom_index` (never *gl_InstanceID*) indexes `GpuInstance[]` (Dim 1 contract); `materials[instance.material_id]` and the vertex/index SSBOs (set 1 bindings 8/9) use the offsets the Rust upload writes. RT gate `sceneFlags.x > 0.5` precedes every fragment-shader ray query (push-constant-gated compute passes excepted).
- Shadow rays: normal/tMin-biased origin, `TerminateOnFirstHit`, point/spot disk vs directional-cone jitter (`sun_angular_radius` 0.020 rad). Reflection: `reflect(viewDir, N)` sign, roughness/metalness gate, barycentric UV from the vertex SSBO. GI: cosine hemisphere, distance cutoff, miss → sky/ambient without NaN/inf. Noise is frame-seeded interleaved-gradient (deterministic so TAA/FSR converge).
- Glass/IOR: Frisvad basis (not `cross(N, up)`); window-portal demote breaks coincident-glass loops; interior miss → cell ambient, not open sky; `MAT_FLAG_THIN_GLASS` sends non-occluding panes down the zero-ray Fresnel path, occluding glass keeps Snell/RT at every RT LOD. The glass ray budget is `qualityTier`-gated (`budgetTier`); `rayBudgetCount` is telemetry only (negative pin on `old + glassRayCost <= rayBudget.glassRayLimit` in `shader_constants.rs`; no CPU reads it).
- `AdaptiveRayBudget` (`ray_budget.rs`; fed `max(main_render_ms, volumetrics_ms)` by `reset_ray_budget`): cold start = tier 0, overload drops at once, headroom is spent only after a long stable window; `--rt-test-ray-quality-tier` pins it (`cold_start_uses_the_watchdog_safe_quality_floor`).
- ReSTIR-DI: neighbour reservoirs are rejected on the 25° cone of the *geometric* normal (`SPATIAL_NORMAL_COS`; octEncoded into `pad0`, reservoir stays 32 B — `RESERVOIR_STRIDE`); surface tag = `inst.surfaceId & RESERVOIR_SURFACE_MASK`. BC1 punch-through: `texColor.a = 1.0` unless `INSTANCE_FLAG_DIFFUSE_ALPHA` (set in `build_and_upload_instances.rs` from `format_has_alpha`, which excludes `BC1_RGBA`).
- Baked sky is read only through `exteriorSkyRadianceOr` / `exteriorSkyDiffuseOr` (`include/bindings.glsl`), gated on `exteriorSkyTint.w`: set 1 binding 20 is PARTIALLY_BOUND, so an ungated `skyCube` read is UB. Every exterior sky-escape site (GI miss, metal reflection, glass reflect/refract miss, water reflection miss) must use the helper (`every_sky_cube_consumer_gates_on_the_ready_flag`, owned by `/audit-exterior`).
- **Coordinate spaces (#1495/#1496)**: raster is render-origin-*relative*; RT is *absolute* (TLAS, ray origins, lighting, fog: `worldPos_rel + render_origin`). Rigid `GpuInstance.model` is rebased on the CPU (`rebase_model_matrix`); `triangle.frag` reconstructs absolute at the top of `main()` so `dFdx/dFdy` consumers see small magnitudes. `RT_ABSOLUTE_PRECISION_CEILING` (2^20, `cell_loader/references/mod.rs`) bounds every absolute-space consumer — a `sin()` of absolute world XZ is the recurring trap.
- **Depth**: reversed-Z sits behind one authority (`DepthMapping` / `ACTIVE_DEPTH_MAPPING`, GLSL `include/depth_convention.glsl`) and ships `Conventional` by design (the flip is an operator RenderDoc job) — do not file "should use reversed-Z", do file any site restating the convention by hand. `NEAR_PLANE_BU_SCALE` (5.0) applies only to BU-scale game content (`Camera::for_content_scale`); measure with `depth.stats`.
**Output**: `/tmp/audit/renderer/dim_2.md`

#### Dimension 3: GPU-struct layout & material table
**Paths**: `scene_buffer/{gpu_types,constants,upload,buffers}.rs`, `crates/renderer/src/vulkan/material.rs`, `shader_constants_data.rs`, `shaders/include/{bindings,shader_constants}.glsl`, the standalone GLSL mirrors (`triangle.vert`, `ui.vert`, `water.vert`, `caustic_splat.comp`, `volumetrics_inject.comp`), `byroredux/src/render/{mod,static_meshes}.rs`.
**First step**: `git log --since=… --format='%h %s' -- crates/renderer/shaders/include/bindings.glsl crates/renderer/src/vulkan/scene_buffer crates/renderer/src/vulkan/material.rs`, then `cargo test -p byroredux-renderer -- scene_buffer material`.
**Floor**: `#[repr(C)]` struct drifting from its shader mirror = HIGH (silent per-instance/per-material corruption).
**Guard**: sizes `gpu_instance_is_160_bytes_std430_compatible`, `gpu_camera_is_368_bytes`, `gpu_light_is_64_bytes` (`scene_buffer/gpu_instance_layout_tests.rs`), `gpu_material_size_is_432_bytes` + `gpu_material_field_offsets_match_shader_contract` (`material_tests.rs`); mirrors `every_shader_struct_is_classified` (`shader_contract_tests.rs`: every GLSL `struct` must be `Guarded` / `MirroredPendingGuard` / `ShaderLocal`) + the per-struct lockstep tests it names; `hash_gpu_material_fields_covers_every_gpu_material_field`. `gpu_material_size_claims` (`material_tests.rs`) scans `.claude/commands/` for stale `GpuMaterial` sizes — a size written here must equal the live one.
**Checklist** (blind spots):
- Every `MirroredPendingGuard` entry (today only `Reservoir`, whose Rust side is a byte-stride constant) is an unguarded Rust↔GLSL contract — diff by hand when either side changed. The ground-cover and bench mirrors are `Guarded` by `name_diverging_glsl_rust_mirrors_stay_in_lockstep`, which runs `assert_glsl_matches_rust` (count, name/order, type; padding compared like any field — both sides spell pads out) — new mirrors go through that table, and a Rust field the GLSL names differently needs a declared `NameAlias`. A `ShaderLocal` classification must be true: a byte stride the host sizes a buffer from is a counterpart, not shader-local.
- Layout tests miss a *semantic* change to an existing lane (`GpuCamera.exterior_sky_tint.w` = sky-bake ready flag, `GpuInstance.surface_id` @108): confirm every reader, the rustdoc and shader-pipeline.md carry the new meaning.
- `GpuMaterial` fields are scalar `f32`/`u32` only (never `[f32;3]`), no padding, so byte identity has no uninitialised bytes; `crate::vulkan::buffer::byte_view` (`NoUninit`) is the one sanctioned view. A new field needs the Rust struct, GLSL `struct GpuMaterial` (only in `include/bindings.glsl`), an offset assertion and its producer (`DrawCommand`/`Material` → `to_gpu_material`).
- Flag constants (`INSTANCE_FLAG_*`, `MATERIAL_KIND_*`, `MAT_FLAG_*`, `DBG_*`/`DBG_BITS`) come from `shader_constants_data.rs` → `include/shader_constants.glsl`, never hand-written shader-side; the `DBG_*` mask already reaches bit 31 (`DBG_VIZ_SELECTED_LIGHT`), so the next flag needs a wider lane.
- Capacity: `MAX_INSTANCES = 0x40000`, `MAX_MATERIALS = 16384`, `MAX_INDIRECT_DRAWS = MAX_INSTANCES`, `MAX_LIGHTS` = 1023 (const-asserted vs the ReSTIR light mask). **Instance SSBOs grow on demand** from `INITIAL_INSTANCE_CAPACITY` (`SceneBuffers::ensure_instance_capacity`, after the frame fence wait): a grow rewrites scene-set bindings 4 and 18 in place, and every *other* descriptor naming the instance buffer must be rebound (`CausticPipeline::rebind_instance_buffer`) — a new consumer needs the same. Uploads clamp to the slot capacity with a one-shot warn; over-cap material intern returns id 0 + `warn!`; the material upload uses the unique count `min(table.len(), MAX_MATERIALS)`, never `interned_count()` (the dedup denominator).
- **Material table**: `MaterialTable::intern`/`intern_by_hash` dedup on `hash_gpu_material_fields` = one `FxHasher::write` over `GpuMaterial::as_bytes` (#4201; `DrawCommand::material_hash` builds the struct and calls it, so lockstep is by construction — `material_hash_matches_gpu_material_field_hash` only guards against a second walk). Dedup-ratio telemetry (`ctx.scratch`) must not drop even when correctness holds; N copies of a material render byte-identically; no per-instance field in `GpuInstance` belongs in `GpuMaterial`. Particle colour fade is quantized (`quantize_fade`, `render/particles.rs`) so it cannot defeat dedup.
- **Neutral-value consumption** (multiplicative roles `detail`, `tint`, `dark`): per-role colour-space handling and shader arithmetic are only correct together and no test ties them — a blank/neutral vanilla map must be the identity (`Material.detail_neutral` → `GpuMaterial`; tint multiply gated on a real alpha channel), not a darkening.
**Output**: `/tmp/audit/renderer/dim_3.md`

### HIGH tier — sync, memory, translation, resolve chain

#### Dimension 4: Synchronization, command recording & pipeline state
**Paths**: `context/{draw,sync_and_acquire_frame,begin_frame_recording,geometry_pass,post_passes,resize,helpers}.rs`, `vulkan/{sync,pipeline,descriptors,gbuffer,reflect,egui_pass}.rs`.

**Floor**: G-buffer format mismatch (shader output vs attachment) = HIGH. Flag every invisible-failure item **needs RenderDoc**.
**Frame shape** (order is in shader-pipeline.md; verify against code): `draw_frame` = `sync_and_acquire_frame` → `begin_frame_recording` → `assemble_camera_and_lights` → `dispatch_skin_and_cluster` (skin, skinned refit, AS barrier, TLAS build, cluster cull, ground-cover scatter) → `build_and_upload_instances` (uploads, sky-cube bake) → `record_geometry_pass` → `record_post_passes` (svgf → caustic → volumetrics → ssao → composite → bloom → taa → upscale → presentation) → egui → screenshot/depth copy. The post-pass helpers are deliberately infallible (`()`): a `?` there skips `queue_submit` after temporal latches were set (#2146/#2503).
**Guard**: `taa_resolves_the_post_bloom_scene_tap`, `record_bloom_pass_skips_raw_correctness_views_before_dispatch` (`post_passes.rs`); `dependency_chain_tests` (`egui_pass.rs`, `depth_capture.rs`); `skin_dispatch_ran_rollback_scope_tests` (`app_frame.rs`); `splits_when_glass_and_z_write_false` / `does_not_split_two_sided_blended_particles` (`draw.rs` — `needs_two_sided_blend_split` = `is_blend && two_sided && order_dependent_glass`; a re-added `z_write` term or dropped glass term is the regression); `scene_descriptor_reflection_tests` (`scene_buffer/mod.rs`).
**Checklist**:
- Per-frame fence waited before command-buffer reuse (`MAX_FRAMES_IN_FLIGHT == 2`, const-asserted; the single shared depth image relies on it). `render_finished` is per **swapchain image**, not per frame. Swapchain recreate waits in-flight work, re-creates every size-derived resource *and* rewrites every descriptor naming it (volumetrics, composite, reservoirs, sky-cube consumers) — a new size-derived resource must be in `context/resize.rs`.
- AS-build **input** reads (vertex/index/instance) use `SHADER_READ` at the build stage, never `ACCELERATION_STRUCTURE_READ_KHR` (that is for AS *structure* reads).
- Hand-offs: render-pass final layouts → SVGF/TAA/SSAO/composite; caustic-accum atomics → `SHADER_READ`; egui and presentation carry their own EXTERNAL dependencies (presentation owns the swapchain attachment and `PRESENT_SRC_KHR`; the UI quad draws inside it — `/audit-ui`). Every cross-pass or cross-submission read, new passes included (ground cover, sky bake, cloud noise), needs its own barrier.
- G-buffer: `triangle.frag` writes eight colour attachments (0–7: HDR, normal, motion, mesh_id, raw_indirect, albedo, FSR reactive, FSR transparency) + depth as 8 — true of that shader only; every other pipeline in the pass (water, ground cover) must write each attachment its blend/write mask enables or mask it off. Formats are in `gbuffer.rs`; audit the *match*.
- Mesh-ID: `R32_UINT`, bit 31 = alpha-blend/no-history; opaque bits 0–30 = stable surface ID, blended = live instance index + 1 (caustic lookup needs live order); overrun is a one-shot `warn!` + clamp.
- Every pipeline that builds its own descriptor-set layout must run `validate_set_layout` (`reflect.rs`) against its shaders (water, presentation, ground cover do; check new ones).
- Vertex input matches `crates/renderer/src/vertex.rs`; push-constant ranges match GLSL; dynamic viewport/scissor (and water `CULL_MODE`) set each frame.
- Pipeline cache: header validated against the device (`validate_pipeline_cache_header`; mismatch → warn + empty cache, never a crash); persisted at teardown and, when lazy blend-variant creation grows it, mid-session (`save_pipeline_cache_if_grown`, `context/helpers.rs`).
**Output**: `/tmp/audit/renderer/dim_4.md`

#### Dimension 5: GPU memory, resource lifecycle & teardown
**Paths**: `vulkan/{buffer,image,allocator,texture,dds,placeholder,device,instance,swapchain}.rs`, `crates/renderer/src/deferred_destroy.rs`, `scene_buffer/`, `acceleration/memory.rs`, `context/{teardown,init,resize}.rs`, `crates/renderer/src/mesh/geometry_ssbo.rs`, `crates/renderer/src/texture_registry/`, `byroredux/src/app_events.rs`.
**First step**: `git log --since=… --format='%h %s' -- crates/renderer/src/vulkan/context/teardown.rs crates/renderer/src/vulkan/buffer.rs crates/renderer/src/mesh`; every resource owner added since needs a `memory-budget.md` ledger row (a pass with none is a finding).
**Floor**: per-frame leak = HIGH; use-after-free of in-flight GPU memory = CRITICAL.
**Guard**: geometry-SSBO rebuild `planning_compaction_does_not_publish_offsets`, `chunked_rebuild_consults_the_idle_threshold_before_duplicating` (`mesh/geometry_ssbo.rs`, `mesh.rs`); `skin_slot_drain_sits_outside_the_skin_compute_guard` (`teardown.rs`).
**Checklist**:
- `VulkanContext` is decomposed into sub-structs (`PostChain` — every post pipeline, `TemporalHistory`, `ScratchBuffers`, `SwapchainTargets`, `OverlayResources`, `FrameSync`) plus directly-owned subsystems. Teardown (`context/teardown.rs`) is **not reverse-creation order** (it starts with `texture_registry`); after `device_wait_idle` only three orderings are load-bearing: `skin_slots` before `skin_compute`; `frame_upscaler::destroy_allocations` after `destroy_device_objects`; `exposure` before the allocator `Arc::try_unwrap`. Do not file "not reverse order"; do verify every allocator-owned object (new passes included) is destroyed *before* `allocator.take()` and any object holding its own `Arc<Allocator>` clone is drained before the `try_unwrap` (else the leak-guard branch deliberately leaks the device).
- `AllocatorResource` is removed from the `World` before `VulkanContext::drop()` (`byroredux/src/app_events.rs`), also on the panic-unwind path. `GpuImage` (`image.rs`) is the one create→allocate→bind→view helper (its allocator lock recovers from poisoning); a hand-rolled image chain regresses it.
- gpu-allocator memory-type correctness (`CpuToGpu` vs `GpuOnly`); FSR's SDK memory is allocated *outside* gpu-allocator (see `FrameUpscaler::resident_bytes`).
- Deferred destroy: `pending_destroy_blas`, `pending_destroy_scratch` (`DeferredDestroyQueue<GpuBuffer>`), the texture registry queue and retired instance-buffer pairs tick `MAX_FRAMES_IN_FLIGHT` frames after the fence wait and drain at shutdown; an immediate destroy at an eviction/unload/grow site is the regression (`build_skinned_blas_batched_on_cmd`'s grow-destroy is immediate by design — it runs after its own fence wait). TLAS resize `device_wait_idle`s before freeing the old allocation.
- Pool/cache policy (`check_pool_growth`, LRU caps, byte-budgeted texture staging): `/audit-performance` Dim 3; here verify `StagingPool` releases its allocator `Arc` on destroy.
- Global geometry SSBO rebuild is chunked/resumable (`advance_geometry_rebuild`, `geometry_rebuild_needs_idle`, `rebuild_geometry_ssbo_atomic_fallback`); compaction is two-phase — only `apply_compaction_plan` may publish offsets (an early publish points every draw at the wrong geometry); a reinstated single-frame rebuild is the regression.
- Every screen/output-extent-scaled resource is billed in `screen_scaled_reservation_bytes` (Dim 1) and ledgered in memory-budget.md.
- Device init (`device.rs`, `instance.rs`, `context/init.rs`): selection requires ray-query + AS + deferred-host-ops, `shaderInt64` and Vulkan 1.3 synchronization2 and prefers hardware devices — RT is mandatory, so `ray_query_supported == false` branches are dead code, not a fallback to maintain; optional caps (timestamps + host-query-reset → GPU timers, `fill_mode_non_solid` → wireframe, `shaderFloat16` → FSR permutation) degrade explicitly; validation layers on in debug, `BYRO_VALIDATION` opt-in in release; the full entry → instance → debug → surface → device → allocator → swapchain → … → sync init chain stays intact.
- Textures: `dds.rs` parses untrusted archive data — truncated headers and unsupported FourCC/DXGI formats must `bail!` (never panic or short-read); `texture.rs` checks `pixel_data.len() >= total_data_size` before upload, but `mip_size` is unchecked `u32` arithmetic (test absurd declared dimensions); upload transitions/staging use the byte-budgeted pool; the 1×1 placeholders are allocator-backed and destroyed before the allocator.
**Output**: `/tmp/audit/renderer/dim_5.md`

#### Dimension 6: Material translation consumption & tangent space
**Paths**: `byroredux/src/material_translate.rs`, `crates/core/src/ecs/components/material.rs`, `byroredux/src/asset_provider/material/`, `byroredux/src/systems/particle.rs`, `byroredux/src/render/particles.rs`, `crates/nif/src/import/mesh/tangent.rs`, `shaders/include/material_sampling.glsl`.
