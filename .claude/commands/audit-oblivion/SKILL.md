# Oblivion Compatibility Audit

Oblivion is the **oldest** title and exercises code no other game reaches. This audit owns **Oblivion's data through the shared mechanisms** (routing: `.claude/commands/_audit-owners.md`): only dimensions whose Paths are Oblivion-specific stay here; a defect in the shared mechanism goes to its owner audit.

**Architecture**: Orchestrator. Each dimension runs as a Task agent (max 3 concurrent).

Read `.claude/commands/_audit-common.md` (layout, methodology, dedup, finding format) and `.claude/commands/_audit-severity.md` for shared protocol.

## What Makes Oblivion Different

Two NIF eras share `Oblivion - Meshes.bsa`: the **retail body** (v20.0.0.4, `bsver` 11, plus a v20.0.0.5 minority; inline strings, u16 flags) and a **v10.x NetImmerse tail** (down to pre-Gamebryo v3.3.0.13) with tight nif.xml version bands. **Neither has a per-block size table**: one N-byte under-read discards the rest of the file (no `block_size` recovery as on 20.2.0.7+), so drift is silent and Oblivion-only. The v10.x stride-drift family (#1506-#1509) is resolved — a **regression-guard set**. The 2026-09-05 CRITICAL (a `NiSkinPartition` reservation: clean rate 100% -> 92.41%, 730 of 9 612 meshes lost) is what a skipped corpus run looks like.

## Phase 1: Setup

1. Parse `$ARGUMENTS`; `mkdir -p /tmp/audit/oblivion`.
2. Dedup baseline: `gh issue list --repo matiaszanolli/ByroRedux --limit 200 --json number,title,state,labels > /tmp/audit/issues.json`.
3. Confirm `Oblivion/Data/` exists; if not, name the dimensions that lose real-data validation.
4. **Run the corpus lane first** (release build; the plain `cargo test` lane never runs it): `cargo test -p byroredux-nif --release --test parse_real_nifs --test per_block_baselines --test block_coverage_baselines --test oblivion_stream_drift_corpus -- --ignored oblivion no_block_sizes`. Any red gate is the headline finding.
5. Scope by delta: `git log --since=<last AUDIT_OBLIVION date> --format='%h %cs %s' -- <dimension Paths>`.
6. Toolchain: the `byroredux` bin crate needs rustc >= 1.96 (wasmtime 49, 15a6b1d2d) — rustup cargo per `docs/contributing.md` § Toolchain note (#4466).
7. Always name `Oblivion.esm` real-data tests (cheap: ~3 s): a whole-crate `cargo test -p byroredux-plugin -- --ignored` spikes >20 GB and can kill the session.

### Dimension 1: NIF Version Handling & Corpus Integrity (v20.0.0.4 + the v10.x tail)
**Subagent**: `legacy-specialist`
Routing: generic stream position / dispatch / version gating -> `/audit-nif`; collision translation -> `/audit-nifal`, `/audit-physics`. This dimension owns the Oblivion-only bands and the corpus.
**Paths**: `crates/nif/src/header.rs`, `crates/nif/src/version.rs`, `crates/nif/src/stream.rs`, `crates/nif/src/lib.rs`, `crates/nif/src/blocks/` (controller/, properties.rs, legacy blocks), `crates/nif/tests/`
**First step**: the Phase 1 corpus lane; `git log --since=<date> --format='%h %cs %s' -- crates/nif/src/header.rs crates/nif/src/blocks crates/nif/src/lib.rs`
- Corpus gates are the guard: 0 truncating, 0 unknown, per-block histogram equal to `oblivion.tsv` (`per_block_baseline_oblivion`, `oblivion_block_count_parity`, `no_block_sizes_drift_detector_has_zero_false_positives_on_real_corpus`). Coverage differs: the histogram gate walks **only** `Oblivion - Meshes.bsa` (8 032 NIFs — `Game::mesh_archives` keeps DLC optional), while `oblivion_block_count_parity` adds the 8 DLC archives (9 612) — a DLC-only histogram shift is invisible to the former. `unknown` growth or `parsed` shrinkage is a stride-drift regression — escalate, do not re-derive; diff the histogram for new block types. The drift corpus (`oblivion_stream_drift_corpus.rs`) resolves its directory through `game_data_dir` and, like the three archive openers, treats a present-but-unopenable archive as a panic via `open_present_archive` (#5439, `5f414d681`; 9 archives, 9 612 NIFs, 0 drift warnings); only a DLC-only directory is skipped. An absent DLC archive is skipped but a present, unopenable one fails (#5780, `c2d3914bf`, `optional_oblivion_mesh_archives_skip_absent_and_reject_present_invalid_files`); extract and parse failures are counted and fail the gate instead of being skipped (#5781, `7869a93fd`); and every sizeless NIF must end its block data on the root footer (`parse_nif_with_options_and_consumed`), with only the eight measured stale-tail Tamriel LOD files in `STALE_TAIL_LOD_FILES` allowlisted (#5782, `6ad0c0214`) — a new entry there is an under-read, not a quirk.
- Header quirks (each pinned; aim at what the pin cannot see — a *new* off-band version): `user_version` exists only for >= v10.0.1.8; BSStreamHeader is the nif.xml dual band `V10_0_1_2 || (user_version >= 3 && (V20_2_0_7 || V20_0_0_5 || (V10_1_0_0..=V20_0_0_4 && user_version <= 11)))` (`bs_stream_header_not_read_for_off_spec_version`, #170); v10.0.0.0..10.1.0.114 blocks carry a leading 4-byte group_id (mixing stream-relative and file offsets is the classic false trail); pre-5.0.0.1 files inline block-type names, decided by version, not by an empty type table (`uses_inline_block_type_names`, #4257).
- `NiTexturingProperty` reads a `u32` shader-map count directly — no leading `Has Shader Textures` bool (nif.xml is wrong; Gamebryo 2.3 is authoritative). Pin: `parse_ni_texturing_property_with_zero_shader_maps` (`crates/nif/src/blocks/properties_tests.rs`, #149).
- `NiGeomMorpherController` trailing field gates on `bsver >= bsver::MORPH_LEGACY_CUTOFF` (10; `blocks/controller/morph.rs`): `doghead.nif` (v10.2.0.0 bsver 9) must skip it, bsver-11 rigs (`obgatemini01.nif`) keep it (`path_lookat_tests.rs`, #1509).
- The sizeless runtime-size-cache recovery must refuse a skip that contradicts the failed block (#3926, `crates/nif/src/lib.rs`) — a plausible-looking recovery is silent mis-alignment.
- Scene walk: `as_ni_node` (`crates/nif/src/import/walk/mod.rs`) unwraps every NiNode-wrapper subclass (`BSOrderedNode`, `NiBillboardNode`, `BsFaceGenNiNode`, …); a missed subclass drops the whole subtree. `NiSwitchNode` / `NiLODNode` deliberately take `switch_active_children` instead (active index / LOD 0 only). All five walkers share a per-walk visited bitset + `MAX_NIF_NODE_DEPTH` (`revisit_guard`, #5485, `cf8730adc`; hostile-input defense owned by `/audit-nif` — vanilla trees visit each block once either way).
- Deep-trace 3 meshes (Heinrich Oaken Halls chandelier, a book, a creature head) through `import_nif_scene`: mesh count + material chain. Tools: `nif_stats`, `recovery_trace` (`crates/nif/examples/`).
**Output**: `/tmp/audit/oblivion/dim_1.md`

### Dimension 2: BSA v103 & ESM Data Slice (Oblivion.esm)
**Subagent**: `general-purpose`
Routing: reader discipline `/audit-parsers`; GRUP walk / `SubReader` / remap / dispatch `/audit-esm`. This dimension owns TES4-only decode branches and their real-data pins.
**Paths**: `crates/bsa/src/archive/`, `crates/plugin/src/esm/records/` (`actor/`, `items.rs`, `climate.rs`, `pathgrid.rs`, `misc/dialogue.rs`, `misc/pack.rs`), `crates/plugin/src/esm/cell/walkers.rs`
**First step**: `cargo test -p byroredux-bsa --release --test bsa_real -- --ignored oblivion`, then `cargo test -p byroredux-plugin --release --test parse_real_esm -- --ignored clas_oblivion_knight race_oblivion` (single named tests).
- **BSA v103** is a regression guard (#699): `oblivion_all_bsas_v103_brute_force_extract_zero_errors` sweeps all 17 archives; the 35 zero-byte `.txt` placeholders Oblivion stores compressed extract as empty files — `BsaArchive::extract` decides the empty-stream edge itself before any decoder, because flate2 1.1.10 reports an empty zlib stream as `UnexpectedEof` (#5073 / #5660, `fa2af0e89`; `extract_returns_empty_for_a_zero_size_compressed_placeholder`, `extract_rejects_a_nonzero_size_with_no_compressed_stream` in `crates/bsa/src/archive/tests.rs`); `embed_file_names` gates on `>= BSA_V_FO3_SKYRIM`, and the "Xbox archive" flag several v103 archives set must not change name handling.
- **16-byte ACBS** (#1650): Oblivion `NPC_`/`CREA` ACBS is 16 B (flags u32 @0, level i16 @10), distinct from the >=24 B FNV/FO3/Skyrim layout, so `parse_npc` needs the `GameKind::Oblivion` arm gated on `len >= 16` *before* the FNV arm (else level defaults to 1 and every actor reads Male). Pins: `oblivion_16byte_acbs_parses_level_and_gender`, `fnv_ignores_16byte_acbs`.
- DIAL/INFO selection: every INFO authors `QSTI` (its own quest), decoded into `InfoRecord.quest` and applied at selection by the FO3/FNV dialogue path (#5271, `dbc07e8f0`; consumer `byroredux/src/systems/npc_dialogue.rs`). Every Oblivion activation opens through the generic `GREETING` topic (#5367 Phase G), so the positional Random stack is live here: the first passing INFO wins, and a Random one rolls with the immediately following passing Random INFOs up to a plain line or a Random End (`Flags1` bit 5; GREETING carries 461 Random INFOs in 102 runs, 57 Random End) (#5397, `0436bea5c`; `earlier_random_set_wins_over_a_later_plain_line`, `random_end_and_plain_lines_bound_the_random_stack` in `crates/scripting/src/dialogue.rs`). No dialogue live gate runs Oblivion (`docs/smoke-tests/dt1-dialogue-layers.sh` is FNV) — the rule is unit-pinned, not verified in a conversation. Topic reachability is a separate, latent gap (#5350, above): the P4 classifier treats every branch-less Oblivion topic as a list entry, not the known-topics set.
- Legacy leveled lists (#4638): TES4 `LVLO` rows may be 8 bytes with no count (default 1; 94 rows / 14 lists) and `LVLD` bit 0x80 is the all-levels flag, not chance-none. Pins: `oblivion_8byte_lvlo_rows_decode_with_default_count`, `lvld_high_bit_is_flag_not_chance_none` (`crates/plugin/src/esm/records/container.rs`).
- **EFID is a 4-char effect code, not a FormID**: SPEL/ENCH/ALCH/INGR effect ids resolve through `EsmIndex::resolve_magic_effect` -> `magic_effects_by_code` on Oblivion (#5084, `ce73f658b`; 142 of 149 distinct SPEL codes resolve, `resolve_magic_effect_routes_oblivion_efid_codes`) and are kept out of the load-order FormID remap (#5076, `9b099b31f`). A new effect consumer that indexes `magic_effects` directly silently no-ops on Oblivion.
- **Corpses are marked on the base actor**: `NPC_`/`CREA` record-header bit 0x80000 *Starts Dead*, decoded only under `GameKind::Oblivion` and ORed onto placements (#5013, `dca2bb401`). Pins: `oblivion_only_base_starts_dead_bit` (`crates/plugin/src/esm/records/dispatch_actor.rs`), `oblivion_starts_dead_bases_and_their_placements_match_the_audit_census` (87 NPC_ + 48 CREA bases, 787 placements).
- **Legacy PACK shapes** (#5504, `dae08000d`): `parse_pack` accepts Oblivion's 4-byte `PKDT` (u16 flags, u8 procedure, junk byte) beside the 8-byte FO3/FNV form, and the 12-byte `PTDT` (type, target, count — no trailing f32). Before this 479 packages read as Find (650 placements) and no package carried a target, so all 208 Follow packages idled. Pins: `oblivion_legacy_pkdt_and_twelve_byte_ptdt_decode` (`misc/pack.rs`), `parse_rate_oblivion_pack_legacy_pkdt_and_ptdt` (`crates/plugin/tests/parse_real_esm.rs`, `--ignored`).
- Other TES4 branches: MGEF-by-code map (`oblivion_mgef_populates_magic_effects_by_code`), CONT 4-byte payload guard, CLMT three-entry WLST keyed on `GameKind`, RACE/CLAS `is_oblivion` / `flags_oblivion` arms (real-data pins above), XCLL sizes `[28, 32, 36]` with the >= 92 ambient-cube arm **game-validated** to Skyrim/FO4/FO76 (`crates/plugin/src/esm/cell/tests/cell.rs`).
- **CLOT enters inventory** as a wearable `ItemKind::Armor` (`parse_clot`: BMDT slots, MODL/MOD3 male/female meshes; SLGM likewise). Pin: `oblivion_clothing_enters_inventory_and_gender_aware_equipment` (`records/tests.rs`). ARMO shares the 4-byte `BMDT` shape (u16 Biped Flags + General Flags byte; FO3/FNV read the low u32 as slots, #5696, `a8e37e5fd`; `oblivion_armo_4byte_bmdt_no_longer_drops_biped_flags` in `items.rs`). The `EsmIndex.clothing` doc now carries the measured 604 (#5086, `e7e8829b9`).
- **Navigation is PGRD-only** (`pathgrid.rs`, 8 228 grids; layout census in its header). As of 2026-10-20 `CellData.pathgrids` still has no consumer beyond the walker: `docs/engine/navmesh-pathfinding.md` covers NAVM only, so Oblivion packages have no path graph.
- DIAL/INFO: with zero `PNAM` / `ANAM`, speakers resolve through the `GetIsID` condition fallback and `build_conversation_tree` must order without PNAM chains (#3600); TCLF / NAME / CTDT and multi-segment responses are kept (#3614, #3616); LVSP (306) dispatches (#3617); SBSP (33) / ROAD (2) are recorded in `RecordType` as deliberate non-goals (#3619).
**Output**: `/tmp/audit/oblivion/dim_2.md`

### Dimension 4: Exterior & Lighting Data (Tamriel)
**Subagent**: `general-purpose`
Routing: WTHR / sun / terrain / LOD / water translation mechanism -> `/audit-exterior`. This dimension checks the Oblivion-only inputs.
**Paths**: `byroredux/src/cell_loader/` (`placement_lod.rs`, `terrain.rs`), `byroredux/src/env_translate/`, `byroredux/src/systems/light_anim.rs`, `crates/plugin/src/esm/cell/`, `docs/engine/exterior-readiness-plan.md`
**First step**: `docs/smoke-tests/m-exteriors.sh oblivion static` (needs a Vulkan device), and `git log --since=<date> --format='%h %cs %s' -- byroredux/src/cell_loader byroredux/src/env_translate`
- **`_far.nif` placement LOD is real only here** (`placement_lod_supported_is_oblivion_only`; FO3/FNV ship none and use `ObjectLodScheme::FalloutLegacyBlocks`): confirm placements and LOD textures still resolve on a Tamriel exterior.
