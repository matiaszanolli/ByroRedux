# UI Audit: Scaleform (R4 + M48) and MenuXml (M48.4-M48.7)

Read `.claude/commands/_audit-common.md` (delta-first scoping, dedup, finding format) and `_audit-severity.md` for shared protocol.

Audits the *host contract* that decides whether a Bethesda menu works, on two tracks that share one overlay compositing path. Orchestrator; one Task agent per dimension (max 3 concurrent).

## Scope

- **Scaleform**: `crates/ui/src/` (`lib.rs` `UiManager`, a stack of `UiLayer`s (one Ruffle player each) and deliberately not an ECS `Resource`; `profile.rs`; `prepare.rs`; `host.rs`; `behaviour.rs` H1-H4 host-call classes; `path.rs` + `avm1_path.rs` + `avm2_host/path_helpers.rs` the path service; `avm1_host.rs` Skyrim scanner; `avm2_host.rs` FO4 `BGSCodeObj` ABC injection; `catalog.rs`; `navigator.rs`; `fonts.rs` + `translate.rs` font classes and `$`-key text; `player.rs` offscreen wgpu; `pacing.rs` render pacer; `input.rs`) and the vendored patched `third_party/ruffle/` (`PATCHES.md`: the `$`-key translation hook, one carried patch); protocol pins `crates/ui/tests/{hudmenu_protocol,fallout4_hudmenu_protocol}.rs`.
- **MenuXml**: `crates/menuxml/src/` (`eval`, `layout`, `raster`, `menu`, `profile` audited here; `parse`, `tex`, `font` are the parse side, owned by `/audit-parsers`).
- **Engine side**: `byroredux/src/{ui_input,ui_state,hud,scaleform_hud}.rs` (`UiState`, the one `App.ui` field group holding the `UiManager`, both HUD drivers, input state, host-call latches and the open dialogue / message-box surfaces, af54da820 #6695), the M48 menu stack `byroredux/src/{menu_stack,menu_drivers,menu_xml_input,menuxml_document,scaleform_dialogue,scaleform_messagebox,menuxml_dialogue,menuxml_message,menuxml_rest,oblivion_rest}.rs` over the `MenuRegistry` resource (`crates/core/src/ecs/resources/menu_registry/`; its per-game flag and code tables are the `menu-flags-*` / `menu-codes-*` TSVs under `docs/data/game-ui/`, compiled in), `crates/core/src/ui_labels.rs` (native-page words from the game's GMSTs), `byroredux/src/commands/hud.rs`, `byroredux/src/app_frame.rs` (`tick_ui_overlay`, `tick_hud_overlay`), `app_events.rs`, `scene.rs` (`--menu`/`--hud` launch), renderer `crates/renderer/src/vulkan/{presentation.rs,texture.rs,context/post_passes.rs,context/build_and_upload_instances.rs}`, `crates/renderer/src/texture_registry/dynamic_rgba.rs` + `crates/renderer/shaders/ui.{vert,frag}`.
- **Handoffs**: GPU teardown order `/audit-concurrency`; Ruffle/wgpu `unsafe` `/audit-safety`; MenuXml XML/DDS/`.fnt` parse robustness `/audit-parsers`; what a HUD *shows* (actor values, inventory) `/audit-gameplay`.

The `host-classes-*` and `target_surface` columns are design *targets*: Phase 3 (d062bf440, #6665) compiled `host-classes-*` into the catalog (`behaviour.rs`, Dim 3), so a *call's* H1-H4 class now reports what it actually met, but a method whose target is H1 and whose runtime class is H3 is an unbuilt handler (M48 Phase 3 rest), not a finding. `crates/ui/tests/avm1_path_access_probe.rs` is hermetic (hand-assembled AVM1 movie, no game data) and pins that an AVM1 adapter can get / set / invoke `_root` members through `ExternalInterface.addCallback` at the pinned Ruffle, and that a bare `eval` cannot tell an absent path from `undefined`; Phase 2 (#6661, 4feb20ae0) built the path service on that result (Dim 1).

**Deliberately unbuilt** (verified 2026-11-20 against `docs/engine/ui.md`; re-verify, do not trust this line): H1 handlers for most host methods (an H3 call gets `Null`; only the 26 `SKYRIM_PLACEHOLDERS` rows answer or deliberately ignore; the menu-stack, path-service, dialogue and message-box surfaces below are built), Papyrus↔UI bridge (the extender `UI.*` functions stay unserved), the HUD-under-a-modal draw rule, Fallout 4 `$MAIN_Font_Bold`-class font mapping and FNV `-s` string defaults (Phase 6), full menu pack (`ui.coverage`: Skyrim SE 27 of 46 menus have a surface, 3 fed; New Vegas 10 of 49, the two pinned counts; Oblivion 7 of 54, pinned since aca40315e (#7095) as 5 documents, 2 native, 47 absent, with no barter rules, its `SleepWaitMenu` / `LevelUpMenu` counting as MenuXml documents (250a5ba67); ROADMAP's matrix keeps its wave-2 dash for Oblivion; the unfed ones are #7042), Starfield HUD bring-up (#4470 is closed, but only its parser blocker shipped: 9813af435 `normalize_scaleform_dialect`; no `ScaleformProfile::Starfield`, Starfield catalog, driver bars, protocol pin or `m48-8` smoke exists). Audit the *mechanism* that will carry them.

**Regression guards**: #3429 (closed; mechanism e2f99ad55): a same-extent `update_rgba` queues into `dynamic_rgba.rs` and is recorded in the next frame's command buffer (persistent image, per-slot staging, no fence wait); only an extent/format change recreates the image. A per-frame image create or fence wait on the overlay path is the regression (see Dim 5).

## Phase 2: Dimensions

### Dim 1: Profile, Prepare & Host Bridge Transport
**Paths**: `crates/ui/src/{profile,prepare,host,lib,path,avm1_path}.rs`, `crates/ui/src/host/tests.rs`
**First step**: `git log --since=D -- crates/ui/src/host.rs crates/ui/src/prepare.rs crates/ui/src/profile.rs crates/ui/src/lib.rs crates/ui/src/path.rs crates/ui/src/avm1_path.rs`
**Guards**: `host/tests.rs::a_response_handler_may_re_enter_its_own_bridge` (handler is cloned out of the map before invocation; a refactor holding one borrow across the call re-introduces the panic); `prepare.rs` tests (`an_archive_menu_open_decompresses_and_parses_once`, `a_loose_avm1_movie_is_decompressed_once_and_never_parsed`, `a_profile_mismatch_is_rejected_before_any_further_decode`) via `SwfDecodeCounts`.
- Profile comes from the SWF header's AS3 bit (`ScaleformProfile::from_header`, `is_action_script_3()` on the decompressed header; Ruffle's movie type is `SwfMovieData` since the b91e82160 nightly-2026-10-10 bump), never from `--game` or archive provenance. A forced `new_with_profile` that contradicts the movie fails loudly or is test-only. The `external_interface_id` used at registration equals the id the bridge filters on (mismatch = every host call vanishes silently). Malformed SWF returns `Err`, not a half-built player.
- Queue: `MAX_QUEUED_CALLS` (1024) evicts oldest with `pop_front`, counts each eviction, warns once. A drained batch may be non-contiguous; the engine (`app_frame.rs`) latches `UiState::dropped_host_calls` per menu and `host_call_gap_for_menu` resets it on a menu swap. Regression = comparing against zero or dropping the latch.
- Every bounded set (`callbacks`, `known_methods`, `unknown_methods`, `unanswered_methods` via `insert_bounded`; the player's error/load lists) caps at `MAX_DISTINCT_HOST_METHOD_NAMES` and logs once at the trip. The engine's own callbacks are exempt from the cap by **exact membership** in `RESERVED_ENGINE_CALLBACKS` (7 names, built from constants in `avm2_host` and `path`: the 3 lifecycle hooks plus the 4 `__byro_path_{get,set,call,attach}` path callbacks, GUI-PATH-004; worst case per set = cap + 7), so movie-registered `__byro*` spoofs cannot lock out `__byroBGSCodeObjReady`/`Loaded`/`Destroy` or the path adapter (8974dec12, #4719 retired the prefix-keyed 32-wide band). A prefix test reappearing anywhere is the regression (the `scaleform_hud.rs` push no longer has a skip at all, Dim 7). The guard sits in `insert_bounded`, the single choke point for all sets; check a new set goes through it.
- **Starfield PlaceObject3 dialect shim** (#4470, 9813af435): `prepare.rs::normalize_scaleform_dialect` runs before every `prepare_movie` stage and once more in the navigator's `load_archive_resource` over every SWF body it serves (1ac34024f, #5480; `navigator.rs::a_dependency_movie_reaches_ruffle_normalized`: Ruffle's response body is the patched FWS, `0x0824` -> `0x0825`; the `ImportAssets` scan parses those same normalized bytes and no longer normalizes a private copy, which also dropped its second whole-stream inflate) and sets MOVE only on PlaceObject3 records with neither MOVE nor HAS_CHARACTER, recursing into DefineSprite (depth-capped at 1: nested sprites are illegal SWF, and an uncapped descent overflowed the stack on a ~10 B/level crafted movie, 8872f3725, #5456; `deeply_nested_sprites_do_not_overflow_the_stack`, `one_level_of_sprite_nesting_is_still_patched`) and re-emitting FWS at a fixed length (`prepare.rs` tests). It must stay length-preserving, fail closed on a malformed body (a CWS body overrunning its declared length is declined, `cws_body_longer_than_its_declared_length_is_declined`; the inflate is bounded by the header's own length **and** the absolute `MAX_SWF_BODY_BYTES` ceiling, 128 MiB, ~2x the largest shipped movie (FO76 `fonts_zhhant.swf`, 65,902,267 B): a header claiming up to `0xFFFFFFFF` over a ~4 MB zlib bomb is declined before any inflate, d601b45ab, #5719; `cws_header_claiming_u32_max_over_a_bomb_is_declined`, `swf_body_ceiling_clears_the_corpus_and_stops_short_of_u32`, `cws_within_the_ceiling_inflates`), and own the prepare path's single decode (15b65b1b9, #5479): on CWS it inflates once and ALWAYS returns the uncompressed file (patched or not) so `swf::decompress_swf` takes the uncompressed copy path; on FWS it returns `Some` only when a record changed; it returns `None` for ZWS, conforming FWS and foreign containers (`conforming_cws_returns_its_decode_with_an_untouched_body`). A shim that inflates the raw bytes separately from the prepare decode is the #5479 regression; `SwfDecodeCounts::decompresses` is measured, not a literal (fixed in b93ccdf7f, #5967 closed: CWS open = 1, FWS = 0, inflate-then-decline = 2; `a_cws_archive_menu_open_inflates_exactly_once`, `a_shim_that_inflates_and_then_declines_still_counts_its_inflate`). **Declared-length ceiling at every decode site** (b93ccdf7f, #5966): the shim's private cap was not enough (the stock `swf::decompress_swf` honours the header's `u32`), so `ensure_declared_len_within_ceiling` runs before `prepare_movie`, both navigator dependency decodes, `ScaleformProfile::detect` and the AVM1/AVM2 scanners, and an over-ceiling claim is a hard `Err` (a recorded degraded dependency on the import path), never a `None` falling through to the stock loader. Source-shape guard `every_decode_site_is_behind_the_declared_length_ceiling` (+ `every_public_decode_entry_refuses_an_over_ceiling_claim`); a new decode site must call it. The navigator fetch is the second choke point (eca8ca620, #6225): `load_archive_resource` refuses any over-ceiling SWF body as a recorded degraded resource whatever asked for it, because a movie a running menu loads (`Loader.load`, `loadClip`, `loadMovie`) is decoded by Ruffle's own `SwfMovieData::from_data`, which no `crates/ui` decode site sees (`a_runtime_loaded_movie_over_the_ceiling_is_refused_before_ruffle_sees_it`). Runtime-loaded movies take the same path, so they reach Ruffle shimmed too (#5480, closed 1ac34024f: regression guard is a navigator fetch that hands Ruffle the raw archive bytes).
- One SWF decode per open: `prepare_movie` → `PreparedMovie`; floor is one inflate (CWS; zero on FWS) + one tag walk, Ruffle's `from_data` taking the shim's uncompressed copy. A stage taking raw bytes again is the regression; `--menu` passes `profile: None` and reads the installed layer's `UiLayer::profile()` afterwards (no pre-extract-and-detect).
- `SwfPlayer::invoke_callback` consults ruffle's own external-interface registry (not only the bridge's recorded name set) before invoking, and prunes a stale name: AVM2 `addCallback(name, null)` unregisters a callback behind the bridge, and invoking it would otherwise reach ruffle's unknown-callback warn and return a `Null` indistinguishable from a live callback's answer (86f5a1a0a). `None` = unknown/unregistered, `Some(Null)` = registered callback returning null. The prune and the empty-URL skip are pinned (b7760069a, #5732: `host/tests.rs::invoking_an_unregistered_callback_prunes_and_returns_none` over the real AVM2 fixture, `navigator.rs::an_empty_import_assets_url_is_skipped_silently`).
- **Path service** (M48 Phase 2, #6661, 6b02f75d0 / 4feb20ae0; GUI-PATH-001…005): `UiLayer::path_op` (`path.rs`) is the only engine code that reads, writes, calls or `Attach`es a movie member by path, through the reserved `__byro_path_*` callbacks (AVM1: a `DoAction` spliced into frame 1 by `avm1_path.rs` on the stock decode's tag stream, no second tag parse, #5479; AVM2: `avm2_host/path_helpers.rs`, so only a movie carrying the `BGSCodeObj` lifecycle class gets it and any other answers `NotReady`). `decode_reply` yields `Found`/`Absent`/`NotReady`/`Queued`; only a number, string or boolean crosses back. `WhenAbsent::Queue` holds an op for retry after every tick (newest per path wins, `MAX_QUEUED_PATH_OPS` 64 per movie) and absent paths are reported once (`MAX_REPORTED_ABSENT_PATHS` 256); a new engine path-by-member access that bypasses `path_op`, or an unbounded queue/report set, is the regression. A present-but-`undefined` AVM1 member reads as absent (AS2 cannot tell). Guards: `avm1_path.rs::avm1_adapter_sets_and_reads_a_root_path`, `path_helpers.rs::{avm2_adapter_reports_an_absent_path, avm2_adapter_attaches_a_named_display_instance_once}` (renderer-less players, no GPU).
- `ScaleformValue` round-trips in both directions with unrepresentable values becoming explicit `Null`; `ScaleformHostDispatch::MissingResponse` (Request with no response) stays distinct from `Unknown`.
- The bridge is `Rc`/`RefCell` (Ruffle is single-threaded): nothing hands a clone to another thread; `UiManager` stays out of the ECS resource set (`ScaleformHudDiag` is the console mirror).
**Output**: `/tmp/audit/ui/dim_1.md`

### Dim 2: AVM2 Adapter Injection (FO4 `BGSCodeObj`), highest risk
**Paths**: `crates/ui/src/avm2_host.rs`, `crates/ui/src/avm2_host/path_helpers.rs`
**First step**: `git log --since=D -- crates/ui/src/avm2_host.rs crates/ui/src/avm2_host/`
**Guards**: `avm2_host.rs::{no_other_injected_name_is_a_prefix_of_another, generated_adapter_pool_carries_no_abandoned_loader_strategy, every_forwarder_is_wired_to_its_own_name}` (the last walks every installed name, with and without the destroy trait: installer pair *i* is (helper *i*, method *i*), script trait *i*+1 is that helper with `disp_id` *i*+1 and its body pushes exactly `BGSCodeObj.<method i>`; added 29740f97a, #6998, because the #6952 builder split was proven byte-identical only against a since-deleted copy), `crates/ui/tests/fallout4_hudmenu_protocol.rs` (data-gated). Bytecode surgery on a third-party binary: a wrong constant-pool index yields a movie that loads and misbehaves, and no test fails.
- Every index written is one the rewriter added or verified (append-then-reference ordering). Injection is idempotent (menu reload / resize rebuild must not duplicate helpers or traits).
- `ScaleformHostObjectState` has four variants (`NotRequired`, `NotPresent`, `AdapterInjected`, `AdapterInjectedWithoutDestroyHook`). The re-injection probe scans for `DESTROYED_EVENT`, not its strict prefix `DESTROY_CALLBACK`; the four destroy strings are emitted together or not at all. Both `scene.rs` menu-load log sites call `UiLayer::host_object_state()` (else `NotPresent` logs like a healthy menu).
- The destroy callback is registered only when the movie's class declares `onCodeObjDestruction`; `AdapterInjectedWithoutDestroyHook` does not increment `code_object_destruction_count()`.
- One shared helper normalises `BGSCodeObj.Method` → `Method` while keeping the transport name in `ScaleformHostCall` (not 269 per-method copies).
- The adapter builder (`build_adapter_abc`, #6952 3cfab7f1d) is one sequencer over `build_adapter_pools` (`AdapterPools`/`AdapterNames`/`DestroyNames`) and `AdapterMethods::add` per method; it must keep the disp-id order, so a new method is a new `add_*` step, not edited pool indices.
- The three path methods plus the `__byro_path_attach` walker (`path_helpers.rs`) register after `onCodeObjCreate` and only on movies with the lifecycle class. The walker checks `k in o` per segment (falling back to `getChildByName` for a display child that is not a declared variable), and `Attach` constructs the exported class from `ApplicationDomain.currentDomain`, requires a `DisplayObject`, names and `addChild`s it, idempotently (#7036). An append-then-reference index error here moves no test the default lane can see except the three path guards (Dim 1).
- Degradation: an unparseable ABC tag or no lifecycle-class match returns the *original* bytes with `NotPresent` + `log::warn!`; the hard `Err` is kept only for `patch_root_constructor` (a partial rewrite would corrupt the SWF). No third branch may silently hard-fail.
**Output**: `/tmp/audit/ui/dim_2.md`

### Dim 3: Catalog Fidelity & the AVM1 Scanner
**Paths**: `crates/ui/src/{catalog,avm1_host,behaviour}.rs`, `crates/ui/src/avm1_host/tests.rs`
**First step**: `git log --since=D -- crates/ui/src/catalog.rs crates/ui/src/avm1_host.rs crates/ui/src/behaviour.rs`
**Guards** (default lane): `catalog.rs::{skyrim_catalog_is_sorted_and_unique, fallout4_catalog_is_sorted_and_unique, fallout4_catalog_provenance_split_matches_the_2966_sweep, skyrim_catalog_is_fully_measured, the_skyrim_measured_kinds_match_their_call_site_arities}` (`find` is a case-sensitive `binary_search_by`, so sortedness under `str::cmp` is its prerequisite). `behaviour.rs::{every_catalog_entry_has_exactly_one_phase0_class, placeholders_are_cited_h2_rows_of_the_right_kind}`. Data-gated: `installed_skyrim_host_calls_are_all_cataloged` (Phase 1; also asserts every method the vanilla archive calls carries a behaviour class).
- Diff the re-derived counts (Phase 1 step 3) against every number in `docs/engine/ui.md`, ROADMAP and prior reports; mismatch = doc rot.
- **Fourth-argument rule** (#4720, 588085f20; #5274, 3df616c12): the AVM1 scanner records each resolved site's `CallMethod` arity as a `(min, max)` pair (`Avm1HostCallInventory::arg_counts`), so a mixed-arity name fails the corpus sweep instead of collapsing onto the max; the sweep pins four-arg ⇔ `Request` for every entry it sees (floor 16 four-arg methods so a quiet scanner fails loudly; synthetic pin `a_four_argument_site_records_the_callback_bearing_count`). A new Skyrim entry must arrive `Measured`; a name-prefix guess there is the regression.
- Only FO4 sweep entries may be `HeuristicNamePrefix` (its #2966 sweep was name-only, no arity); a `Command`/`Request` mis-type on a heuristic entry is lower confidence than on a `Measured` one. `kind` only selects a diagnostic bucket (`record_call` queues every call and answers from the configured response regardless), so a misclassification moves a name between `unanswered_methods()` and `Queued`; it cannot drop a call. Spot-check high-traffic methods against the installed-ABC/SkyUI evidence in `docs/engine/ui.md`.
- AVM1 scanner: `GameDelegate.call` operands are read right-to-left; function bodies are nested byte slices and the constant pool descends with the walk; the stack is cleared on unmodelled actions (can lose a site, never invent one); `Avm1HostCallInventory::unresolved` counts recognised-but-unnamed sites. Runtime-named calls (`this.callbackName`) are invisible to a static walk; the catalog is a union, not a proof of completeness.
- **Behaviour classes** (M48 GUI-HOST-001…004, d062bf440, #6665): `ScaleformHostCatalog::behaviour(name)` is Phase 0's per-method *target* (H1 served / H2 placeholder / H3 unserved, from `host-classes-{skyrim,fallout4}.tsv` compiled in); `ScaleformHostCall::class` is what the call *met*: H1 only when the engine registered a handler (or answered a configured response), H2 only when `SKYRIM_PLACEHOLDERS` realizes it **and** the placeholder's kind fits the catalog kind (`Ignore` for a `Command`, `Answer` for a `Request`), H3 for any other cataloged method (the movie gets `Null`, never an invented value), H4 for an uncataloged one. A placeholder answer without a cited reason in the TSV, or an H3 call answered with a made-up value, is the regression. The drain's once-per-`(menu, method)` diagnostic fires for H3/H4 and names class and target; `UiState::host_reports` / `ui.host [menu]` count per class, bounded like the bridge's sets.
- `unknown_methods()` is live, not test-only: the frame driver warns once per `(menu, method)` (`UiState::reported_host_methods`, bounded by the same cap, one-shot `reported_host_methods_capped` latch) and the set is not cleared per frame or per menu load.
**Output**: `/tmp/audit/ui/dim_3.md`

### Dim 4: Resource Navigator (archive-backed loads)
**Paths**: `crates/ui/src/{navigator,fonts,translate}.rs`, `crates/ui/src/player.rs` (load side)
**First step**: `git log --since=D -- crates/ui/src/navigator.rs crates/ui/src/fonts.rs crates/ui/src/translate.rs`
**Guards**: `archive_menu_route_tests` in `byroredux/src/scene.rs` (CLI-argument parser only); `docs/smoke-tests/m48-menu-load.sh` (Vulkan + game data) is the only end-to-end gate.
- Movies are **untrusted content**; URL→archive resolution is confined to the game archives (`archive_movie_url` rejects `..` escapes; `resolve_url` joins against the movie URL). Verify absolute paths, non-archive schemes and network/filesystem escapes are refused (escape = HIGH); one backslash/case normalisation point matching `byroredux/src/asset_provider/`.
