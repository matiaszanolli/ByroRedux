# Performance Audit

Read `.claude/commands/_audit-common.md` and `.claude/commands/_audit-severity.md` for shared protocol (layout, methodology, dedup, context rules, path-reference convention, finding format, hot-path hashing rule).

Audit ByroRedux for CPU hot-path inefficiency, per-frame allocation churn, draw/instancing waste, GPU memory pressure + eviction thrash, SSBO sizing/upload cost, pass cost and streaming stalls. **Do not re-derive memory ceilings** — `docs/engine/memory-budget.md` owns every size, threshold, reserve floor and VRAM budget; cite it.

**Architecture**: Orchestrator. Each dimension runs as a Task agent (max 3 concurrent). Always pass the Agent tool's `model` parameter — otherwise the agent inherits the session model. `model: "haiku"` for a guard-only dimension (no commits since the last report: it runs named tests and checks symbols exist); `model: "sonnet"` for a dimension with a changed delta (it traces new code and judges it).

Hardware target: **RTX 4070 Ti (12 GB) + Ryzen 7950X (16c/32t)**; RT VRAM minimum 6 GB. A CPU bottleneck here is a **bug**, not a tuning gap — dimensions are ordered by per-frame impact.

## Parameters

- `--focus <dimensions>`: comma-separated numbers (e.g. `1,3,5`). Default all 8. `--depth shallow|deep`: pattern scan vs traced + quantified. Default `deep`.

## Extra Per-Finding Fields

- **Dimension**: CPU Hot Paths | Draw & Instancing | GPU Memory Pressure | SSBO Sizing & Upload | GPU Pipeline | Skinning & BLAS | Streaming & Cells | NIF Parse | Telemetry & Origin Cost

## Bench discipline (never hard-code numbers)

- ROADMAP.md carries the **live Bench-of-record** (`scripts/fsr-bench-matrix.sh 3 300`, `renderer-stepped`, five scenes × TAA/FSR presets, with a same-machine control of the outgoing record): read it, its open regressions (**R6a-regress-22**: the "FO4 frame time doubled inside `4c9a5b36..99933f87b`" reading was `b9e961eeb` moving the bench camera's spawn origin into the room, not code — #5128's pinned-pose control; the known-open residual is ≈ +0.7 ms / fence +2.6 ms from the old pose, the top-of-frame all-slots fence wait tracked as #5365. Before comparing two bench records, check their `camera_pos` columns match; and **R6a-regress-23**: the live record is `d9a201c71` (2026-10-22, controlled against `a3a7a43b0`), and HEAD reads 1–9% slower than that control on every scene — Cornell, the content-identical one, +0.99 ms TAA; the SVGF bracket is +0.22–0.35 ms (the `gpu_shadow_filter` bracket inside it) and *gpu_main* +0.5–1.2 ms on Cornell / Whiterun / MedTek is unattributed) and the compat table; report **observed-vs-ROADMAP deltas** — a regression is a delta. Scenes: Cornell (redistributable control), Prospector (FNV), WhiterunBanneredMare (Skyrim), MedTekResearch01 + Dugout Inn (FO4).
- Run shape: `--bench-frames N [--bench-hold] [--bench-mode renderer-static|renderer-stepped|system-live]`. Compare only within one mode (baseline TSVs in `.claude/audit-baselines/runtime/` are renderer-static; the record is renderer-stepped); the mode owns delta-time, so never set `BYROREDUX_FIXED_DT`. Point `BYROREDUX_SETTINGS_PATH` at a fresh file and pass `--upscaler` explicitly, or a persisted `render.upscaler` changes the run (#4947); the `bench:` line reports `upscaler=`/`render_extent=`/`output_extent=`. Measure the noise floor first (`scripts/bench-variability-envelope.sh`); a delta inside it is not a finding.
- **Harness byte-stability.** `scripts/fsr-bench-matrix.sh` + `scripts/fsr_bench_report.py` must stay byte-stable across commits or cross-commit comparisons mean nothing. Never assert it from memory (#4024): run `scripts/check-bench-harness-provenance.sh [--strict] [<record-commit>]` (full history required) and quote the verdict; a *DIVERGED* verdict → re-bench both sides. An edit to either file that was not itself re-benched is a finding (against the live `d9a201c71` record the verdict is byte-stable (`fc83608d3`'s `gpu_shadow_filter` column append predates it; the `a3a7a43b0` record reads DIVERGED with two edits, `fc83608d3` (#5959) and `994620123` (#6316, the *gpu_cloud_shadow* column; its disposition landed with #6336, `a74c2bdf0`), each carrying a recorded disposition; the older `a37fcba3c` record reads DIVERGED with four, each carrying a recorded disposition the script prints — #5451, fixed in `4b9472909`: the Prospector `Update.bsa` mount was shown measurement-neutral by a same-session interleaved control, the `camera_pos` and `gpu_shadow_filter` columns are append-only. Without `--strict` a DIVERGED verdict still exits 0; dispositions annotate only, the verdict, exit code and `--strict` are unchanged).
- **Adaptive ray budget**: the RT quality tier follows GPU time (`AdaptiveRayBudget`), so a lighting-cost delta is uninterpretable without it — pin with `--rt-test-ray-quality-tier N` for A/B, else report the tier.
- **Hooks** (`byro-dbg` after `--bench-hold`; no `bench-stats` command exists): the once-a-second `gpu_ms:` / `cpu_ms:` lines, `MetricsSnapshot` (over the wire `MetricsPayload` carries `gpu_pass_ms`, `cpu_pass_ms` and `top_systems_ms`, so `byro-dbg` can name the slow system and the slow CPU bucket without log scraping; #6278, `05d94dd61`), console `ctx.scratch`, `skin.coverage`, `rt.integrity`, `depth.stats`. Cite a timer, not a guess.

## Regression-guard posture

Each dimension lists landed fixes as `Guard:` lines — **verify the symbol/test still exists and holds; never re-propose a landed fix** (noise); an eroded guard is a real finding, reported apart from new issues. Std `HashMap`/`HashSet` on a per-frame per-entity keyspace is a fresh regression (the Fx conversion is finished). Falsified by measurement, re-propose only with new numbers: decorate-sort-undecorate for the raster sort (#4194, `manual_bench_draw_sort_decorate_sort_undecorate`, `render/draw_sort_key_tests.rs`).

**Alloc coverage**: NIF parse/import allocation is dhat-testable (`dhat-heap` feature; bounds in `crates/nif/tests/heap_allocation_bounds*.rs`) — propose a bound, don't estimate. Per-frame render/ECS paths have NO dhat coverage: flag "no quantitative guard exists for this site".

### Dimension 3: GPU memory pressure & eviction thrash
**Paths**: `crates/renderer/src/vulkan/acceleration/{predicates,blas_static,constants}.rs`, `context/resources.rs`, `crates/renderer/src/texture_registry/`, `crates/renderer/src/mesh.rs`, `byroredux/src/streaming_helpers.rs` (`exterior_pool_reserve`, `defer_geometry_rebuild`), `byroredux/src/asset_provider/material/{provider,cdb,loose_mat}.rs`, `crates/sfmaterial/src/index.rs` (the Phase-2 `MaterialIndex`), `crates/renderer/src/deferred_destroy.rs`.
**First step**: `git log --since=… --format='%h %s' -- crates/renderer/src/vulkan/acceleration crates/renderer/src/texture_registry crates/renderer/src/vulkan/context/resources.rs`; `rt.integrity` shows BLAS residency, missing/evicted counts and pending-destroy backlog.
**Guard**: `cargo test -p byroredux-renderer --lib acceleration` (admission/eviction/residency tests), `static_blas_recovery_covers_both_sources_and_protects_current_draws` (`resources.rs`), bin `static_blas_recovery_runs_between_frames_not_in_the_render_driver` (`app_step.rs`); `has_any_view_of_path_finds_every_key_variant` (#5053: the prefetch planner's residency probe rewrites one reused key buffer, never 16 `String`s per probe).
**Checklist** (ceilings: memory-budget.md):
- BLAS budget is **dynamic**: `blas_budget_for_heap` = (DEVICE_LOCAL heap − `screen_scaled_reservation_bytes`) / 3, clamped to [`MIN_BLAS_BUDGET_BYTES` 256 MB, `MAX_BLAS_BUDGET_BYTES` 1 GB]; the reservation (`render_extent_bytes_per_pixel_x1024`) bills every render-extent pass — including ReSTIR's `RESERVOIR_BYTES_PER_PIXEL_PER_SLOT` and `SHADOW_FILTER_BYTES_PER_PIXEL` per frame in flight (#6035, `9762d9fa2`) — the upscaler's output-extent images and FSR SDK bytes and is re-derived on resize/upscaler switch; a new screen-sized allocation missing from it starts eviction late. Eviction runs pre- and mid-batch (`blas_over_budget` counts the batch's `pending_bytes`; `BATCH_EVICTION_CHECK_INTERVAL` = 64); admission is bounded on *resident* bytes (`admit_next_static_blas`, `blas_admission_exhausted`) — allocating past residency, or evicting against bytes still in `pending_destroy_blas`, is the regression. LRU must not rebuild-thrash during streaming.
- Static-BLAS recovery stays a deadline-bounded between-frames step; `plan_static_blas_restore` must still skip a set that cannot fit the budget (else evict→rebuild never converges — the ~95 k-draw Starfield city).
