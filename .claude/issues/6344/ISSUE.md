# REN-D7-01: Regression of #6247 (incomplete fix): exterior sun GpuLight still re-keys the SVGF/caustic scene key every frame

- **Issue**: #6344 (snapshot as filed; GitHub is authoritative for live state)
- **Labels**: medium, renderer, pipeline, bug
- **Source**: docs/audits/AUDIT_RENDERER_2026-10-24.md

- **Severity**: MEDIUM (denoiser convergence; visual only, no memory or sync hazard; the same class #6247 was filed for)
- **Dimension**: Denoiser/Composite (also touches Dim 8 caustics and the ReSTIR parked mode)
- **Location**: `VulkanContext::build_and_upload_instances` (`crates/renderer/src/vulkan/context/build_and_upload_instances.rs`): the `for light in lights { ... fold_caustic_key_f32(caustic_scene_key, *v) }` loop over `position_radius` / `color_type` / `direction_angle` / `params`, which runs before `fold_svgf_scene_inputs`, `caustic_key_static` and `svgf_scene_static`; producer `collect_lights` (`byroredux/src/render/lights.rs`); writer `weather_system` (`byroredux/src/systems/weather.rs`).
- **Status**: NEW — incomplete fix of closed #6247 (`68ecd0819`); not covered by open #6315 (that one is the per-frame material re-hash cost).
- **Description**: #6247 removed `sky.sun_direction`, `sky.sun_color`, `sun_illuminance`, the TOD colours, fog and DALC lanes from the discrete key because `weather_system` re-interpolates them from the fractional hour every frame, and moved them to the drift-tolerant `svgf_continuous_inputs_jumped`. The same per-frame quantities still enter the key through the light rig. In exteriors `weather_system` writes `cell_lit.directional_dir = sun_dir` and `cell_lit.directional_color = sunlight` every frame (the `if !cell_lit.is_interior` block). `collect_lights` pushes that as `lights[0]` (`direction_angle = cell_lit.directional_dir`, `color_type` from `cell_lit.directional_color`). `build_and_upload_instances` folds every float of every light with `fold_caustic_key_f32` = `(key ^ v.to_bits()).wrapping_mul(PRIME)` — bit-exact, no tolerance. Any ULP of sun drift therefore changes `caustic_scene_key`, so `caustic_key_static = caustic_scene_key == self.prev_caustic_scene_key && !continuous_jumped` is false; `svgf_scene_static`, `svgf_history_valid` and `caustic_history_valid` fall with it, and so does ReSTIR mode 2 (`scene_static_last_build`). That is the #6247 symptom: a parked camera never leaves the recovery alpha floor and the caustic accumulator restarts every frame. Interiors are unaffected (the XCLL directional is constant; `weather_system` skips `cell_lit` when `is_interior`); a paused clock is unaffected.
- **Evidence**: orchestrator re-read: `for light in lights { for v in light.position_radius.iter().chain(light.color_type.iter()).chain(light.direction_angle.iter()).chain(light.params.iter()) { caustic_scene_key = fold_caustic_key_f32(caustic_scene_key, *v); } }` sits immediately above `fold_svgf_scene_inputs(caustic_scene_key, ...)`; `weather.rs` assigns `cell_lit.directional_color = sunlight; cell_lit.directional_dir = sun_dir;` unconditionally every frame beside `cell_lit.ambient = ambient`. Why the guards miss it: `material_and_sky_discrete_changes_rekey_progressive_history`, `per_frame_animated_material_lanes_do_not_rekey_history`, `continuous_sky_and_fog_reset_history_on_a_jump_not_on_drift` and `continuously_scrolling_clouds_do_not_rekey_history` call `fold_svgf_scene_inputs` / `svgf_continuous_inputs_jumped` directly; none drives the light-rig fold or composes the full `caustic_key_static` expression with a drifting sun light. They are not vacuous for the helpers, but they cannot see this. The magnitude is **derived from the code trace, not measured** (no engine launched).
- **Impact**: every daytime exterior with the game clock running (the normal case) keeps SVGF indirect at the recovery floor with the camera parked and restarts the caustic accumulator each frame — the residual still-camera boiling #6247 was meant to remove — and pays the #6247 per-frame continuous-input comparison for no benefit in exteriors.
- **Related**: #6247 (closed), #4046 (light rig added to the SVGF gate), #5369 (`light_rig_geometry_key` is intensity-blind but keys on the sun *direction*, so ReSTIR mode 3 has the analogous exterior drift), #6315.
- **Suggested Fix**: fold the scene-key directional (slot 0, identity `[0, 2, 0, 0]` in `light_ids`) out of the bit-exact rig fold and into `svgf_continuous_inputs` (its colour and direction lanes), so it is jump-compared like `sky.sun_direction`; keep point and spot lights in the exact fold. Pin it with a test that drives the composed key: a one-frame sun-light drift keeps `caustic_key_static`, a `time.set`-sized jump clears it once. **NEEDS-RENDERDOC**: parked camera in a sunny FNV/Skyrim exterior with the clock running — `svgf_history_valid` (the progressive flag in `params.w`) should engage after the fix; today it should read the recovery floor every frame.
