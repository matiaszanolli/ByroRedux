# #6906 MUS verify: New Vegas ALOC NAM1 bits, audio-marker overlap, battle-set precedence, Dungeon Suspense trigger

Split from #6902, which the GECK wiki dump (archive.org `wiki-geckwikicom`, now under `/mnt/data/src/reference/geckwiki`) settled except for these. `FalloutNV.exe` is SteamStub-encrypted, so none of them can be traced in code. Design: `docs/engine/music.md` §6, §10.

- **`ALOC.NAM1`** (xEdit: "Flags and Enums, messily combined"). GECK *Media Location Controller* documents what it holds but not the bit layout: the **Looping Options** (Loop: "Loop through the Media Location Set in the active list"; Random: "Choose a random Media Location Set in the active list"; Retrigger and None: "Unknown") and **Faction Not Found** (Neutral / Ally / Location / Enemy / None / Friend, used "if there is no faction relation"). Vanilla values: 0x44 ×48, 0x54 ×37, 0x40 ×2, 0x55 ×1, 0x45 ×1. 0x40 is on every controller. 0x10 is on 38, mostly the generic multi-set controllers. The low nibble is 0 on Goodsprings and Doc Mitchell, 5 on SmallRV and ViperHwy95 (all relation-only), and 4 elsewhere. A plausible reading: low nibble = Faction Not Found, 0x10 = Random, 0x40 = "Use Defaults" day/night. That is inference, not a source, so the engine still plays each list's first set and uses Neutral when there is no relation.
- **Marker overlap:** none of the dump's pages says which of two overlapping audio markers wins. The engine picks the one the player is deepest into.
- **Battle precedence:** a controller's Battle sets ("to use when the player is in Battle"), the active Dungeon set's Battle track ("while the player is engaged in combat") and the region's `RDSB` all name combat music. The engine plays them in that order.
- **Dungeon Suspense:** "while enemies are on alert (unverified)". The engine has no alert state (waits on the Sneak and Detection PRD), so the Explore track plays.
- **Location Delay (`NAM4`) and Retrigger Delay (`NAM7`):** "Unknown" in the GECK.
