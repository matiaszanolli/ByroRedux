FSR3 becoming the default upscaler *and* predates the bench mode it now invokes.

- Status: **Regression of #1320**

  commits, 272 touching shaders.

## #3854 — TD1-2026-09-05-05 (LOW, `scripting`, `tech-debt`)
`fragment.rs` is 2538 production LOC of 2540 total, with a 519-LOC
`apply_effect` and 18 near-identical `populate_*` entry points.

- `crates/scripting/src/fragment.rs`; tests already in `fragment/tests.rs`
- Suggested split: `fragment/{mod,state,populate,effects,systems}.rs`
- Second half of the suggested fix: give `apply_effect` one private helper per
  effect family so each arm becomes a one-line delegate.

## #3863 — TD2-2026-09-05-06 (LOW, `tech-debt`)
`extensions.rs` repeats the guest-entry snapshot prologue ten times and the
11-field `DeliveryCommitContext` literal fourteen times.

- `byroredux/src/extensions.rs` (~5920 production LOC; largest file in the tree)
- 10 `set_principal_storage_snapshot` production sites, each paired 1:1 with a
  `set_legacy_container_snapshot`
- 14 `DeliveryCommitContext { … }` literals × 11 fields ≈ 154 lines of plumbing
- Suggested fix: group nine owned fields into a `DeliveryState` sub-struct;
  extract the prologue as a free `fn enter_guest(..) -> PrincipalId`.

## #3864 — TD2-2026-09-05-07 (LOW, `nif-parser`, `tech-debt`)
111 hand-written full-field `NifHeader` literals across 40 files, with ~18 rival
local factory functions, while `NifHeader::detached` produces exactly that value.

- `crates/nif/src/header.rs::detached` (1 production caller,
  `import/precombine.rs`)
- Suggested fix: migrate fixtures to `detached`, using
  `NifHeader { strings, max_string_length, ..detached(v, uv, uv2) }` where a
  string table is needed; delete the per-file factories in favour of one
  `#[cfg(test)] pub(crate)` helper per recurring game preset.
