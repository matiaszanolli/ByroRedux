## Dimension 2: Compute -> AS -> Fragment chains (volumetrics), deep

Order walked in `VolumetricsPipeline::dispatch` (`volumetrics.rs:759-1193`), called from `record_volumetrics_pass` (`post_passes.rs:677`):

1. **Latches.** `tlas_written`, `lights_written` and `boundary_geometry_written` are set by `write_tlas`, `write_lights_and_clusters` and `write_boundary_geometry` inside the same `if let (Some(tlas), Some(lights), Some(geometry))` block that calls `dispatch` (`post_passes.rs:799-984`). `dispatch` asserts and resets all three before any early `?` (`volumetrics.rs:777-797`), so they stay symmetric. The `?` sites in `dispatch` (`begin_frame`, the `write_mapped*` calls, `write_params`) all precede the first recorded command (the HOST barrier at `:997`), so an `Err` returns with nothing recorded. The caller maps `Err` to `ran = false` and runs `record_neutral_frame` or `record_skipped_frame`, which reset `history_valid`, `dispatched_this_frame`, `TransportFieldState` and the local-grid history.
2. **Host to device.** `param_buffers`, `fog_volume_buffers`, `fog_cluster_*`, the occupancy mask and the local-grid `params_buffers[frame]` are written per slot at record time. The previous reader of each is two submissions old and retired by the all-slots fence wait (`sync.rs` rider list, #5215). A global `HOST_WRITE -> UNIFORM_READ|SHADER_READ|SHADER_WRITE` barrier follows (defense-in-depth per #4182). The moment and stats readback buffers are `create_host_readback`; each drain does `invalidate_if_needed`, read, `fill(0)`, `flush_if_needed`, and the writes land before that barrier.
3. **Stage B history barriers.** Five field families (`lighting_volumes`, `emission_history_volumes`, `combustion_state/dynamics/optical_volumes`) get `[frame]` read-to-write and `[previous]` write-to-read in one COMPUTE to COMPUTE barrier. The occupancy mask's cross-frame RAW rests on the global `SHADER_WRITE -> SHADER_READ` COMPUTE barrier at `post_passes.rs:840` (documented at `volumetrics.rs:1022-1033`; still the only edge, so any narrowing is a syncval change).
4. **Stage B2 local grid** (`local_grid.rs:1081-1290`). The irradiance read-to-write and write-to-read barrier is unconditional. If `has_work()`, `record_sim` does `cmd_fill_buffer(bricks[frame])`, then a `TRANSFER -> COMPUTE` barrier, then the atlas history barriers for `state`, `dynamics` and `optical`, the dispatch, and a publish of all three COMPUTE to COMPUTE before inject samples them. `GpuLocalGridParams::new(.., has_work(), ..)` and `record_frame` use the same predicate, with no mutation between (`write_params` at `:1059`, `record_sim` at `:1108`). Brick buffer usage carries `TRANSFER_DST` (`:872`).
5. **Stage C to F.** Inject to integrate is `inj_to_int` plus `pre_int_write` (src `COMPUTE|FRAGMENT|TRANSFER`, access `SHADER_READ|TRANSFER_WRITE`, covering the neutral-clear case from #3647). Stage F publishes `integrated`, `state`, `optical` and `irradiance` as `COMPUTE -> FRAGMENT` and the brick buffer as a global COMPUTE to FRAGMENT memory barrier. A `COMPUTE -> HOST` barrier publishes the moment and stats atomics. Composite reads only `integrated_views`, params, `state`, `optical`, `irradiance`, bricks and the phase table (`composite.rs`, `init.rs:724-778`, `resize.rs:1120-1131`); `dynamics` is read only by inject and the sim, and is published to them by `record_sim`'s trailing barrier. `lighting_volumes` is never read by composite.
6. **Skip / neutral path.** The pending skip-clear latch is set at `post_passes.rs:1014` and promoted only in `promote_skip_clear_latches` (post-submit). `!ran` also calls `clear_local_grid_params`, which zeroes the slot's table so composite cannot march stale atlas images. On a resize the new pipeline's images are cleared to `(0,0,0,1)` in `initialize_layouts`, matching the neutral clear, so a surviving `volumetrics_cleared_on_skip[frame]` latch stays truthful.
7. **TLAS visibility for the inject ray queries.** The post-build barrier is `AS_BUILD/AS_WRITE -> FRAGMENT|COMPUTE/AS_READ` (`dispatch_skin_and_cluster.rs:405-415`), and the stale-handle fallback keeps the same dst mask, so compute ray queries see the TLAS. `volumetrics_inject.comp` reads the static global vertex buffer through `vertexOffset` (alpha UVs only) and never dereferences `skinnedVertexAddress`; none of its include chain reaches `ray_hit.glsl`, `gpu_instance.glsl` or `buffer_references.glsl` (grep). The `skin_publish_barrier_consumer_tests` blind spot therefore does not apply to it.
8. **Transport state machine.** `TransportFieldState::prepare` takes `active == true` to `empty.fill(false)` (conservative even if the buffer is abandoned) and `pending_clear` is committed only by `submitted()` from `mark_frame_completed`; `record_skipped_frame` resets the whole struct. The moment-buffer dirty flag (`combustion_moment_dirty`) is set at record time and cleared only by a drain that zeroes, which is the safe direction.
9. **Process-global state.** `bfecc_error_correction_multiplier`, `sun_alpha_trace_enabled`, `open_sky_sun_dust_per_meter` and `local_grid_debug_bits` are all `OnceLock` (one `env::var` each, no per-frame read); `noise.rs` caches are `OnceLock`s whose init closures nest only distinct locks (`HISTOGRAMS` -> `BASE_NOISE_CACHE`), no cycle.

### CONC-2026-11-09-2.1: brick-buffer `cmd_fill_buffer` has no unconditional FRAGMENT -> TRANSFER edge back to composite's read two frames earlier
- **Severity**: LOW (**PLAUSIBLE, not CONFIRMED**; no validation capture exists)
- **Dimension**: Compute -> AS -> Fragment Chains
- **Location**: `crates/renderer/src/vulkan/volumetrics/local_grid.rs:1203-1213` (`record_sim`), reader at `composite.frag` binding 16 (bricks)
- **Status**: NEW. Refines a hypothesis the baseline dropped (`AUDIT_CONCURRENCY_2026-11-08.md` Dim 2 section 5, "Local-grid WAR on `bricks[frame]` ..."); no open or closed issue found (searched local grid, bricks, WAR, syncval).
- **Description**: `record_sim` clears `bricks[frame]` with `vkCmdFillBuffer` (TRANSFER stage). The same buffer was last read by composite's FRAGMENT shader in the frame two submissions earlier. `record_sim`'s own barrier is `TRANSFER -> COMPUTE` after the fill and says nothing about the earlier read. The baseline dismissed the WAR because the depth-history copy barrier (src `FRAGMENT_SHADER`, dst `TRANSFER`) "covers the `cmd_fill_buffer`". That barrier is emitted only when `has_effect_soft_material` is set (`draw.rs:370-380`). The other FRAGMENT-source barriers I expect in the frame (the SVGF and SSAO entry barriers were not individually read; the Stage D `pre_int_write` was) have a COMPUTE destination stage, and a COMPUTE-dst barrier does not order a later TRANSFER-stage command. A FRAGMENT to TRANSFER edge therefore exists only on frames that also record the soft-particle depth copy, a HUD or UI upload (`record_pending_rgba_uploads`), a capture copy, or the ground-cover counter fill.
- **Evidence**: `local_grid.rs:1203-1213` (fill, then `TRANSFER -> COMPUTE` barrier only); `draw.rs:370-380` (the conditional copy); `post_passes.rs:230-262` (its barrier, `FRAGMENT` src -> `TRANSFER` dst). The image analogues (`state`, `optical`, `irradiance`) do not have this gap, because COMPUTE-dst barriers suffice for compute writes and every default configuration has a FRAGMENT-src barrier to COMPUTE in the frame in between.
- **Trigger Conditions**: a scene with at least one local-grid box, no soft-particle effect material, no HUD and no capture, under `BYRO_VALIDATION=1` (synchronization validation). Hardware execution is not at risk: `sync_and_acquire_frame.rs` waits on every in-flight fence, so frames never overlap on the queue.
- **Impact**: a possible `SYNC-HAZARD-WRITE-AFTER-READ` on a `volumetrics` brick buffer, which would redden a `vulkan-validation` run on a fire scene. Nothing user-visible.
- **Verification Path**: `BYRO_VALIDATION=1` (not `cargo test`). Confirming signal: a `SYNC-HAZARD-WRITE-AFTER-READ` naming a brick-buffer `VkBuffer`, with `vkCmdFillBuffer` as the later access and composite's draw as the earlier read, on a flame cell with the soft-material bit off. Absence of the report on such a capture closes this row.
- **Related**: baseline Dim 2 section 5; `sync.rs` rider note that the host fence is not a device edge.
- **Suggested Fix**: only after confirmation, add `FRAGMENT_SHADER -> TRANSFER` (`SHADER_READ -> TRANSFER_WRITE`) to the buffer barrier ahead of the fill in `record_sim`, or widen the Stage D `pre_int_write` destination to include `TRANSFER` (it is already recorded before the next frame's fill, but after this frame's).

## Hypotheses considered and dropped

- **A `draw_frame` tail `Err` (`end_command_buffer`, `reset_fences`, `queue_submit`) leaves volumetrics temporal state vouching for a discarded frame.** `VolumetricsPipeline::{history_valid, dispatched_this_frame, pending_simulation_time_seconds, transport_fields.pending_clear}` and `LocalGrid::{dispatched_this_frame, stats_pending}` are set at record time and only `mark_frame_completed` advances the committed half; they are not rolled back on a tail `Err`, so the next dispatch would read a `previous` slot that was never written. Dropped as unreachable: `draw_frame` has one caller (`app_frame.rs:782`) and any `Err` ends the process (`app_frame.rs:943-945`, `event_loop.exit()`). Same class as baseline 2.1 but with no remaining live path; re-raise if a retry-after-error mode is ever added.
- **Stale previous-slot occupancy mask after a skipped frame.** The mask is read only through `transportOccupied`, which only gates work inside `transportCombustion`; the history it would feed is gated off by `prev_camera_pos.w` while `history_valid` is false (shader `samplePreviousTransport` returns false). Wasted work at worst.
- **Descriptor-set updates racing a bound set.** `descriptor_sets[frame]` bindings 2, 3-5, 19-21 and 32 are rewritten every dispatch frame before the first bind of that set in the command buffer (`record_frame` and the inject bind both follow the writes); the bindless set 1 is the registry's per-frame set, whose promotions are deferred to `begin_frame`.
- **WAR of composite's fragment reads against the sim and inject writes of the atlas, `optical`, `irradiance` and `integrated` images.** Chain exists through Stage D `pre_int_write` (src `FRAGMENT`, read) or the neutral-clear barrier (read); the SVGF/SSAO entry barriers (src fragment/colour-attachment, dst COMPUTE) are presumed, not read, for the frame where both neighbours skip. Only the buffer fill (finding 2.1) is TRANSFER-stage.
