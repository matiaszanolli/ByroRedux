# Fallout: New Vegas Compatibility Audit — 2026-07-25

Reference-title audit, run as one leg of a `comprehensive` audit-suite
sweep. FNV is the most-validated end-to-end path in ByroRedux and the
reference realization for NIFAL (material/collision translation) and
PHYSAL (ragdoll slice 1). All 9 dimensions were worked directly in a
single session against the live tree at HEAD `ca7a4e0e` — no sub-agent
delegation — combining source-code re-verification, full `cargo test
--workspace` execution, the two `--ignored` real-data parse-rate
suites, and a live headless engine run against on-disk FNV game data
(interior bench-of-record, exterior grid load, and a `byro-dbg`
attach exercising `tex.missing` / `tex.loaded` / `stats` / `entities`).

## Executive Summary

**0 NEW findings, 0 CRITICAL, 0 HIGH, 0 MEDIUM, 0 LOW.** Every checklist
item across all 9 dimensions was independently re-verified against
current source, current tests, and (for Dimensions 1/3/5/8) a live
engine run against real FNV data — and every item held. This includes
re-confirming, from scratch, that **all 9 findings from the prior
`AUDIT_FNV_2026-07-16.md` report are now fixed**: FNV-D1-02 (`#2078`,
`invalidate_nif_cache_on_archive_change`), FNV-D4-01/D4-02 (`#2080`,
OTFT/LVLI/LVLN/CONT + NPC FaceGen-recipe FormID remap), FNV-D4-03/D4-04
(`#2081`, Varmint Rifle test key + stale record-count doc), FNV-D6-01
(ping-pong `reverse_direction` text-key fix), FNV-D7-01 (`#2083`,
`activate_ragdoll` re-activation guard calls `remove_ragdoll` on the
prior instance), and FNV-D8-01/D8-03 (bench-of-record refreshed
multiple times since; `CLAUDE.md`'s Asset Provider row already
documents the directory split).

The one open, tracked issue that touches FNV — **PERF-REGRESSION-6c56e311**
(HIGH, ROADMAP Known Issues) — was independently reproduced this session
at native (TAA) resolution: Prospector Saloon read **67.9 FPS / 14.72 ms
wall** against the pre-regression `142.0` FPS reference, matching the
previously-documented ~64.7–68.5 FPS range almost exactly. This is not a
new finding (it is fully described and root-caused in `ROADMAP.md` Known
Issues, diagnosed as an inherent cost of two deliberate shader features —
`traceShadowTransmittance` glass-aware shadows and the bounded-path-tracer
GI bounce — not a bug), so it is carried forward here as a live
regression-status confirmation, not re-filed. Note for the Baseline
Comparison table below: with the engine's new FSR 3.1 Quality default
(`5c7acfe2`), the *effective* Prospector number a normal run sees is
136.6 FPS (853×480 internal → 1280×720 output) — FSR shades fewer
pixels and masks most of the regression's user-visible impact without
fixing the underlying native-resolution cost, exactly as the ROADMAP
entry warns.

### Dimension 3 — RT Lighting Pipeline — FNV Scenes

**No new findings.** All checklist items re-verified against current
shader + Rust source:

- TLAS deliberately keeps off-screen occluders in the acceleration
  structure — frustum culling gates only rasterization
  (`in_raster`), not TLAS membership
  (`crates/renderer/src/vulkan/acceleration/tlas.rs:64-73`, `#419`/`#516`)
  — so no in-view fragment can lose a shadow/reflection/GI ray hit to
  an out-of-frustum occluder being dropped.
- `NUM_RESERVOIRS = 16` confirmed at `triangle.frag:2152`; ReSTIR-DI
  lives in `include/lighting.glsl` as documented.
- BLAS budget: `compute_blas_budget` (`predicates.rs:578-584`) is
  exactly `(device_local_bytes / 3).max(MIN_BLAS_BUDGET_BYTES)` with
  `MIN_BLAS_BUDGET_BYTES = 256 MiB` (`constants.rs:61`) — matches the
  skill's ~4 GB-at-12 GB-VRAM description, cached in `blas_budget_bytes`.
- SVGF temporal accumulation reads `mesh_id` + a normal-consistency tap
  for disocclusion rejection (`svgf_temporal.comp:17-262`); TAA uses
  Halton jitter + YCoCg variance clamping (`taa.comp:45-228`).
- `MAT_FLAG_PBR_BSDF = 32u` (`shader_constants.glsl:81`) is only ever
  set CPU-side via `ImportedMesh.is_pbr`, which is only flipped `true`
  by the BGSM/BGEM merge path (`byroredux/src/asset_provider/material.rs:704,783,938`)
  or a `.mat` external-material merge — FNV never authors either format,
  so the Disney-BSDF lobe remains unreachable for FNV content, confirmed
  by grep across the whole importer (no other `is_pbr = true` write site
  exists outside those two merge functions and test fixtures).
- `#1125` skyTint interior gate: both raytrace.glsl miss-fallback sites
  (`:247` return, `:286` mix) share the same `missCol` variable, gated
  on `_isExt = jitter.w > 0.5` (`:158-159`) — an interior cell (no
  `SkyParamsRes`) correctly falls to cell-ambient-only.
- Sun-sprite mip-0 force (`8b5d77c1`) confirmed at
  `composite.frag:289` (`textureLod(..., 0.0)`).
