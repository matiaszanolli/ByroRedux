## BGSM Consumption Table

How each external-material field flows: parsed by `crates/bgsm/` → merged into
`ImportedMesh` by `merge_bgsm_into_mesh` (`asset_provider/material.rs`) →
surfaced on the canonical `Material` post-NIFAL (`translate_material` +
`resolve_pbr`).

| BGSM field | Merged into `ImportedMesh` (`material.rs`) | On canonical `Material` (post-NIFAL) |
|---|---|---|
| Diffuse/albedo tint | `:854` | base color |
| Specular color | `:978` → `bgsm_metalness` `:85-98` | `metalness` (saturation for non-pbr / F0-luminance for pbr) |
| Smoothness | `:846` `roughness_override = (1.0 - smoothness).clamp(0.04,1)` | `roughness` (resolve-once; NaN backstop skipped) |
| Emissive | `:972` | emissive color/mult |
| Translucency suite (#1147) | `:957` | `BGSM_TRANSLUCENCY` → `MAT_FLAG_PBR_BSDF` translucency |
| Model-space-normals bit | `:945` | `BGSM_MODEL_SPACE_NORMALS` |
| Texture slots (diffuse/normal/spec/glow/…) | `:856-922` | texture handles |
| src/dst blend | `bgsm_blend_to_gamebryo` `:620` (plain `u8`) | Gamebryo→VK blend factors (Standard 6,7 / Additive 6,0 / Mult 4,1) |
| PBR flag (`leaf.pbr`) | routes metalness branch `:841` | `BGSM_PBR` → shader `MAT_FLAG_PBR_BSDF` (Disney lobe) |

Merge is **OR-upgrade only** — it never clobbers NIF-derived flags to false.
`merge_bgsm_into_mesh` runs at import, strictly before `translate_material` /
`resolve_pbr`. Template `.bgsm` inheritance is cycle-safe (#1148, `DEPTH_LIMIT=16`).

## Forward Scope Chain

Ordered, and deliberately **excluding** anything shipped (CSG reader, BGSM
parser, SCOL/PKIN expansion — never list these as pending):

1. **Precombine collision** (`_precomb.nif`) + **`.uvd` occlusion volumes** —
   the M49 Stage-B sub-items. FO4 architecture today gets synthesized trimesh
   colliders via the shared static path; authored convex hulls + occlusion
   culling are the next fidelity/perf step.

   Havok-driven movable/destructible runtime is unbuilt (parse-vs-drive
   boundary is honest — nothing pretends to drive it).

   is correct; FO4 uses `BhkSystemBinary` NP-blob ragdolls, blocked on that
   decode (tracked under the PHYSAL layer).
4. **Deeper cell coverage** — LIGH power state, CONT leveled items, NPC_ face
   morph. Records parse; the gameplay/visual consumers are incremental.
5. **`BSBehaviorGraphExtraData` behavior-graph driving** — parsed (3 fields),
   zero consumers, drives no animation. Behavior-graph runtime is far-forward.
