## BGSM Consumption Table

Unchanged from 2026-07-24 (no logic touched this session — see delta note
above). How each external-material field flows: parsed by `crates/bgsm/` →
merged into `ImportedMesh` by `merge_bgsm_into_mesh`
(`byroredux/src/asset_provider/material.rs`) → surfaced on the canonical
`Material` post-NIFAL (`translate_material` + `resolve_pbr`).

| BGSM field | Merged into `ImportedMesh` (`material.rs`) | On canonical `Material` (post-NIFAL) |
|---|---|---|
| Diffuse/albedo tint | `:854` | base color |
| Specular color | `:978` → `bgsm_metalness` `:85-98` | `metalness` (saturation for non-pbr / F0-luminance for pbr) |
| Smoothness | `:846` `roughness_override = (1.0 - smoothness).clamp(0.04,1)` | `roughness` (resolve-once; NaN backstop skipped) |
| Emissive | `:972` | emissive color/mult |
| Translucency suite (#1147) | `:957` | `BGSM_TRANSLUCENCY` → `MAT_FLAG_PBR_BSDF` translucency |
| Model-space-normals bit | `:945` | `BGSM_MODEL_SPACE_NORMALS` |
| Texture slots (diffuse/normal/spec/glow/…) | `:856-922` | texture handles |
| src/dst blend | `bgsm_blend_to_gamebryo` `:620` (plain `u8`) | Gamebryo→VK blend factors (Standard 6,7 / Additive 6,0 / Mult 4,1) |
| PBR flag (`leaf.pbr`) | routes metalness branch `:841` | `BGSM_PBR` → shader `MAT_FLAG_PBR_BSDF` (Disney lobe) |

Merge is **OR-upgrade only** — it never clobbers NIF-derived flags to
false. `merge_bgsm_into_mesh` runs at import, strictly before
`translate_material` / `resolve_pbr`. Template `.bgsm` inheritance is
cycle-safe (#1148, `DEPTH_LIMIT=16`).
