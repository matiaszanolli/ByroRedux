# Light & Shadow Correctness Campaign — NIFAL + EXAL (6 games, FO76 excluded)

**Goal:** light and shadows render correctly in interiors and exteriors across Oblivion, FO3, FNV, Skyrim SE, FO4, Starfield, by fixing the concrete known defects at the NIFAL/EXAL translation boundaries and their shader consumers.

**Working agreement (per project conventions):**
- Exploration confirmed the defect set. Three findings were **recently fixed** (do not re-touch): NIF light −Z aim (#4395), spotlights-as-omni (#2205/#2439), blade zero-sun (#4291), sky-miss sites (#4292). Several backlog findings are **unfiled** — each gets filed as an issue when fixed (audit-publish conventions; only place issues are created).
- Every fix: re-verify the cited site first (audits go stale), root-cause, unit/regression test, conventional commit. No per-game branches downstream of NIFAL/EXAL — per-game knowledge enters only inside the translate boundaries.
- **This sandbox has no GPU.** I land code + `cargo test` + `glslangValidator`-recompiled SPIR-V + oracle/smoke harnesses; each wave ends with a device checklist (exact commands) for you to run on the 4070 Ti. Shaders touched → bench-of-record refresh owed (R6a discipline), noted per wave.
- **Out of scope:** FO76 entirely; Starfield CDB Phase 2 (#3398, separate effort); new features (cloud shadow maps, moving-cloud taxonomy beyond citation) unless a wave has slack.

## Wave 1 — HIGH lit-response bugs + concrete translation defects (no device needed to land)

2. **#4423 (HIGH)** tint role weights `_sk` RGB by its alpha; vanilla `_sk` is alpha-less DXT1 → skin albedo × (0.09, 0.02, 0.02). Gate on alpha-channel presence.
3. **#4424 (HIGH, FO4)** `_s.dds` smooth-spec bound as both gloss and specular-color; BC5 zeroes blue → every direct highlight broken. Rebind per BGSM role semantics (`fill_from_bgsm` path; overlaps #4434 — fix together).

5. **Per-game falloff-exponent sentinel**: `LightData.falloff_exponent == 0.0` must mean 1.0 (Skyrim+) / 2.0 (pre-Skyrim) per its own doc contract (`crates/plugin/src/esm/cell/mod.rs:704-726`), but one shared default 1.0 applies everywhere (`lighting.rs:280`). Fix at the construction site; affects Oblivion/FO3/FNV quadratic falloff intent.
6. **`sunlight_dimmer` unwired**: parsed (`weather.rs:150,563`), zero consumers. Wire through EXAL (`env_translate.rs`) into the sun-intensity envelope in `weather_system` — per-weather sun dimming currently ignored on every game.
7. **cloud_march height-fraction bug** (unfiled, AUDIT_RENDERER_2026-09-14 D18-02): height derived from flat `position.y` compresses cloud vertical profile toward horizon. Shader fix + file the issue.
8. **#3305 (MEDIUM)** dynamic actors cast no ground-contact shadow (repro FO4 Commonwealth). Trace creature TLAS instance/visibility masks (`blas_skinned`/`tlas.rs` path); fix mask or TLAS inclusion; pin with a unit test on the mask decision fn.
